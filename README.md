# ゲームの森

咲華のAndroidゲーム APKダウンロードサイトです。

公開サイト: https://poetsakihana.github.io/game-no-mori/

## ゲームを公開する

Releasesで新しいリリースを作り、APKを添付して公開すると、サイトのゲーム一覧にダウンロードリンクが自動表示されます。

詳しい手順は [ADD_GAMES.md](./ADD_GAMES.md) を参照してください。

スマートフォン対応・ゲーム名検索・並べ替えに対応。APK未登録時は開園準備中と表示します。

APKはAndroid専用です。iPhone・iPadではインストールできません。
