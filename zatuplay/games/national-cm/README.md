# 全国ローカルCM ブラウザ版

**3.0.0-web.1** / `games/national-cm/`

元APK「11.全国ローカル-cm-v3.0.0.apk」の実アプリ『全国CM まちめぐり』を移植しています。元のCSSによるテレビ等のイラスト、地域検索、公式掲載・継承候補の区別、あとで見る、履歴、動画のローカル追加、CSV出力、YouTubeプレーヤーと出典リンクを保持しています。ポイント獲得や勝敗・エンディングのあるゲームではなく、CMコレクションを閲覧する作品です。

- APK SHA-256: `618840440e851411a09b0463d0edc9228372f704acee95645e77cb2d8e1675e8`
- 元データ: **32,319件**。元APKで公式掲載を照合した227件と、未確認の継承候補32,092件。
- 47都道府県、自治体マスター1,917件、公式動画に対応する149市町村という元データを保持。
- 元の全レコード・全自治体・統計の値と順序を保持。分割データを結合した正規化SHA-256が原本と一致します。元のCSSも一致します。詳細は `SOURCE_ASSETS.json`。
- 動画本体やサムネイルはダウンロード・複製・再配信していません。原本の全レコードはYouTube動画ID付きURLです。検索結果ページのリンクを動画の代わりに登録したものではありません。
- **32,319件すべての現時点の実在・再生可否を検証したものではありません。** 「公式掲載を照合」は原本の2026年11月3日の出典照合区分で、今回全出典を再照合したという意味でも、再生確認済みという意味でもありません。動画の削除・非公開・年齢/地域制限・埋め込み禁止があり得ます。

## 起動・操作

HTTP(S)で `index.html` を配信します。上部の相対リンクでZatuPlayのブラウザ一覧へ戻れます。

1. 初期表示は公式掲載を照合した227件です。「全国共通」は11件。「地域から」で都道府県を選び、市区町村・企業名・CM名・年代で絞り込めます。
2. 星ボタンで「あとで見る」に登録。CMを開くと「履歴」に記録します。履歴は詳細を開いた記録で、視聴完了の証明ではありません。
3. 「埋め込みで視聴」を押した時に初めてYouTubeのAPI・プレーヤーへ接続します。自動再生はせず、プレーヤーの再生ボタンを押します。
4. 埋め込み不可や接続失敗は明示し、「もう一度読み込む」「YouTubeで開く」「出典ページ」で対応できます。再生制限を回避する機能はありません。
5. 「継承候補も含める」で残り32,092件を読み込みます。初回の追加受信は合計約35.5 MB（非圧縮値）です。進捗と通信失敗を表示し、途中失敗では既存一覧を壊さず再試行できます。
6. 「動画を追加」はこのブラウザだけへの登録です。公開カタログや第三者へ投稿しません。YouTubeの動画URL・CM名・地域を指定します。重複確認のため、まだ未読込の場合は継承候補のデータを取得します。追加中に閉じた操作が後から勝手に確定しないよう保護しています。
7. 「一覧をCSV保存」は全ページを含む現在の検索結果をUTF-8で保存します。CSVから保存記録を復元する機能はありません。

狭い画面、44px以上の主要操作、キーボードのフォーカス、モーダル終了後のフォーカス復帰、件数の読み上げ通知を補強しています。320px程度の幅ではカードを1列にします。レイアウトの実ブラウザ確認は下記の未検証欄を参照してください。

## 保存・通信・中断

- 保存キーは原本と同じ `cm-travel-v3`。お気に入り・詳細を開いた履歴・自分で追加した動画をlocalStorageに保存します。APK版・別端末・別ブラウザとは同期しません。
- 保存は各操作直後。保存取得拒否、容量不足、壊れたJSON、null、異なる型、不正な追加レコードに対応しています。壊れた元データは自動削除・上書きせず、読める部分だけ使用します。
- 保存失敗は上部に残し、成功と表示しません。現在のタブでは操作できても、閉じると未保存の変更が失われます。未保存時は対応ブラウザで離脱確認を求めます。
- 別タブで同じ保存キーが変更された場合や書込直前に不一致を検出した場合は、古いタブからの上書きを止めます。同じ作品は1タブで使ってください。
- 初期表示・再読込・候補データ読込・動画視聴に通信が必要です。オフライン起動は保証しません。検索語や保存内容をこのサイトのサーバーへ送信する処理はありません。YouTubeへの接続と外部リンクは上記の操作後に限ります。
- タブ非表示時は動画を一時停止し、戻っただけでは再生しません。ページ離脱時はプレーヤーを破棄します。プレーヤー内をクリックするとwindowのフォーカスが移るため、単なるwindow blurでは停止させません。
- 読込中のモーダル開閉・同じ動画の再表示・別動画への変更で古い非同期結果が新しい画面を上書きしないよう識別します。API・iframe準備に16秒のタイムアウトと再試行を用意しています。

## 自動検証

```sh
node zatuplay-source/scripts/test-national-cm.cjs
cd zatuplay-source && npm run build
```

テストはNode VMと最小限のDOM代替を使います。YouTube APIは制御可能なテスト代替です。ブラウザ画面や動画の実再生を確認するものではありません。

- 元の全32,319件、1,917自治体、統計、CSSのハッシュ。source / 配信ミラーの一致。
- 初期検索227件、全国共通11件、愛知2件、コメリ検索9件、ページ切替・条件リセット・47都道府県。
- 星登録・解除、履歴、保存・再読込、継承候補のお気に入り復元、キーボード操作後のフォーカス。
- 候補の段階読込・通信失敗・再試行・選択変更との競合・表示された条件と実結果の一致。
- null/不正JSON/型不正/不正追加データ、保存取得拒否・容量不足・回復、別タブ更新の上書き防止。
- 動画のローカル追加・再読込・重複拒否・不正URL拒否・年代条件リセット・追加中の閉じる→再表示で古い入力を確定しないこと。
- CSVの検索件数、UTF-8、数式として解釈される文字列のエスケープ。
- 明示操作前にYouTubeを呼ばないこと、プレーヤーの開閉競合、API/iframeタイムアウト、埋め込み拒否時の外部リンク、一時停止・破棄・自動再生なし。

## 実ブラウザ確認

**公開前検証用。一般公開URLでのChrome実操作、代表動画の再生または正当なYouTube遷移、実ダウンロードのCSV、保存と再読込はまだ未確認です。** ローカルChromeは環境のソケット制限で起動できないことが既知のため、この作業では再起動や制限回避を試していません。

公開後の確認担当者は、通常UIで地域/キーワード検索→動画詳細→星登録→履歴→再読込、代表CMの再生または外部YouTubeへの遷移、追加（自分の端末内）・重複拒否・CSVダウンロード・戻るリンクを確認してください。動画例は初期全国共通のコメリ「CRUZARD」 (`NmxC3xwWqv4`)。現在の再生可否は未確認です。制限表示が出た場合は記録し、回避しないでください。

スマホ実機、タッチ、Safari/Firefox、スクリーンリーダー、音の実聴取、全動画・全検索条件の実操作は未確認です。公開実操作の記録とカタログ登録は確認後に追記してください。
