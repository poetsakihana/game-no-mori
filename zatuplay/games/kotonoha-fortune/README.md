# ことのは占い ブラウザ版

版: **1.0.3-web.1** / catalog: `collection-10`

原本「10.ことのは占い_1.0.3.apk」内の HTML / JavaScript を直接移植した、ブラウザだけで動く作品です。Android版APKそのものは変更しません。外部ライブラリ、外部画像、API、認証、課金、送信はありません。占いは自己理解のための娯楽で、未来や他人の気持ちの断定、専門鑑定、医療等の判断には使えません。

## 原本を保持した内容

- 基本10方式 × 20相談テーマ × 5視点 = 1000メニュー。架空の案内役4人、深掘り相談と履歴。
- 独自オラクル500テーマ（25世界観 × 20意図）。各テーマ22象徴。
- 占術100項目: 簡易実行11、独自ワーク29、記録のみ60。原本と同じ対応区分で、未実装の専門計算をできると表示しません。
- カード一覧11,114枚: タロット78 + ルノルマン36 + 独自オラクル500 × 22。原本のローカルSVG生成を保持。タロット自動抽選は大アルカナ22枚。
- 市販デッキ参考115件: オラクル60、タロット30、ルノルマン25。商品画像・公式解説・販売機能はありません。原本の価格と商品名は参考情報で、現在の販売状況は未確認です。
- 手持ちカードのジャーナル、プロフィール、過去の相談、JSONバックアップ。

原本5ファイルのハッシュは `provenance.json`、元コードを実行して展開した全データ表のハッシュと件数は `content-manifest.json`。`gallery.js` は原本と同一です。Androidネイティブの書出し橋 `android.js` はブラウザ版では不要のため含めません。APK署名やネイティブ実行物は配布しません。

## ブラウザ移植の変更

- 専用保存キー `zatuplay:kotonoha-fortune:v1`。元の `kotonoha-v1` や他作品の保存を読書きしません。Android版のJSONは明示的に復元できます。
- `Web Locks` の排他区間で現在の保存バイト列を照合して書込みます。他タブの更新を認めたら上書きを停止します。非対応環境では危険なCAS代替を使わず、メモリ内利用とJSON書出しに限定します。
- 相談・結果・プロフィール・ジャーナル・100占術履歴に加え、入力途中、選択、フィルター、現在画面、相談の継続先を保存します。
- 壊れた／将来版の保存を自動初期化しません。旧保存の退避とJSON書出しを提供。容量不足・アクセス拒否を表示し、結果と入力はメモリに保持します。書込み成功前に復元・全削除を成功扱いにしません。
- JSON復元はサイズ制限、構造・配列・日時・重複ID等を検査し、確認後だけ置換します。取消・失敗でもファイル入力を初期化し、同じファイルを選び直せます。復元中の通常保存を抑制し、古いスナップショットの再上書きを防ぎます。確認後のロック待ち中に入力が変われば復元・削除を中止し、新しい入力を保護します。
- カード演出中の連打を抑制。Escape、スキップ、タブ非表示、blur、pagehideで演出タイマーを停止し、既に引いた結果を表示します。リロード後も保存済みカードは再抽選しません。
- 生年月日は実在する今日以前の日付を検査。UUIDがない環境でローカルIDを生成し、暗号乱数非対応環境は娯楽用の簡易乱数へ。ネット送信を禁止するCSP、ラベル関連付け、フォーカス、狭幅画面、dialog未対応時の閉じる操作を追加。

## 保存とプライバシー

入力した相談や生年月日等はこのブラウザの同じサイト領域にだけ保存します。端末間同期はありません。同じサイトの管理者側コードからはブラウザ保存を読めるため、秘密情報や実在する第三者の機微な情報は入力しないでください。

JSONにも相談・生年月日・未送信の入力途中が含まれます。安全な場所に保管し、共有先に注意してください。プライベートモード、ブラウザ設定、サイトデータ削除、端末容量で保存が使えない／消える場合があります。閉じる前に画面上部の保存表示を確認してください。ブラウザの強制終了や電源断では最後の非同期保存が完了しない可能性があります。重要な記録はJSONでも保管してください。

## 検証と未確認

専用 `test-kotonoha-fortune.cjs` は、原本由来の全データ表／件数、全11,114 SVGの生成、代表SVGの実デコード、10基本方式、100占術、市販115デッキ、継続相談、入力復帰、演出中断、保存拒否／容量不足、壊れた保存、競合、Web Locks非対応、復元取消・再選択・異常形式、テキストエスケープ、全ファイルのミラー一致を検査します。

検証用の `linkedom` と `@napi-rs/canvas` を利用できる環境で、リポジトリ直下から `node zatuplay-source/scripts/test-kotonoha-fortune.cjs` を実行します。専用の `sync-kotonoha-fortune.cjs` は、この作品だけのchecksumと公開用ミラーを同期します。

VMとlinkedomでDOMイベントを発火し、SVGはnative Canvasライブラリでデコードします。タイマー・localStorage・Web Locks・download・focusはモデルです。実Chromeのレイアウト、タッチ、OSダウンロード／ファイル選択、別プロセスのWeb Locks、GitHub Pagesでの動作を検証したことにはなりません。本版の制作時点ではそれらの本番QAは親工程で別途行います。

### 本番Chromeの短いQA

1. タイトル→案内役→相談。架空の相談でカードを引き、演出を進め／スキップして結果を確認。追加相談とリロードで履歴を確認。
2. 「占い100種類」からグランタブロー36枚、数秘、相性、記録専用の各1件。「カード一覧」の全件表示数・絞込み・拡大・表裏を確認。
3. 入力途中の相談・プロフィール・手持ちカードを残してリロード。演出中にタブを隠し再開し、二重抽選されないことを確認。
4. JSON書出し→復元取消→同じJSONを再選択→確認復元。元の記録に戻ること、出力に機微な架空データが含まれる旨の表示を確認。
5. 同じ作品を2タブ開き、両方に異なる架空入力を入力。後から保存した側は競合表示と書出しが可能で、先の保存を上書きしないことを確認。360px幅も確認。

未確認を実施済みとは記録しません。公開版の確認結果はリリース管理側に記録します。
