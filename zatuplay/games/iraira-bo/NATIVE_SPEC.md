# 元APKとの対応

対象: `09.イライラ棒-v1.0.apk`、Android package `jp.sakihana.irairabo`。
元APKはHTML/WebViewではなく、`MainActivity$Game` がAndroid Canvasで描くネイティブ作品です。画像・録音音源・Web資産はありません。原APKのバイナリは変更していません。非署名4エントリーのSHA-256は `provenance.json` に記録しています。

## 座標と生成式

元画面は360×800。ステージ番号を0始まりのL、i=0..220、t=(float)i/220、a=(double)t×πとすると、中心線は次の221点です。

```text
x = 180 + sin(a) × [(75 + min(L,20)×1.4) × sin((L%6+2)×a + 0.59×L)
                    + 22×sin(10×a + L)]
y = 666 - 500×t
通路幅 = 74 - 1.12×L
制限時間 = 75 - L 秒
```

元DEXではsinと引数がdouble、sinの戻り値はfloatへ変換され、その他の演算もfloatです。`model.js` は演算ごとのMath.froundを使用。検証用の `scripts/generate-iraira-reference.py` はDEXの定数と演算順を独立にPythonのfloat32で計算し、全6,630頂点・30通路幅・30制限時間を基準データへ書き出します。これはAPK実機画面や人間による攻略の比較ではありません。

## 入力・衝突・進行

- 棒の半径8。指/ポインターが棒から65未満の距離ならつかむ。以後の相対移動量×0.8を棒に加える。
- 1回の移動は長さ/2の切上げ回数に分割。各点から全220線分への最短距離が「幅/2−8」を超えたら失敗。飛び越しを許可しない。
- 各点の衝突検査後、最終点との距離が15未満ならクリア。ちょうど15はクリアではない。
- 経過時間が制限時間を超えると失敗。指を離しただけでは時間は止まらない。一時停止では時間も止まる。
- ステージ0の幅74/制限75秒から、ステージ29の幅約41.52/制限46秒まで、難易度式は変更しない。
- 初期解放数1。クリア時は `max(現在の解放数,min(30,L+2))`。既クリア面の再挑戦は後半の解放を増やさない。
- 最短時間だけをBESTとして更新。元APKの保存は解放数・30面のBEST・音設定。ブラウザは追加で途中位置/時間/画面を保存し、実行中の保存は停止画面として読み込む。
- 失敗は「壁に当たった！」「時間切れ！」、同面リトライ、最初から、ステージ選択。最終面は「全ステージ制覇！」。

## 画面・音

元の紺背景 `(7,15,29)`、24pxグリッド `(15,29,46)`、シアン `(39,229,210)`、文字 `(234,244,255)`、補助文字 `(146,166,188)`、金 `(255,209,102)` を保持。通路の外枠は幅+5、内側は `(17,38,54)`。ゴール半径15、棒半径8/中心3、影14。タイトル図形・文字の位置、2列×5行のステージ選択と3ページ、停止/失敗/クリアのパネル位置は元Canvas座標から移植。

操作ボタンはブラウザの実HTMLボタンで、同じ座標に重ねています。Tab/Enter、ポインター、タッチの操作を可能にしています。Webフォント・外部画像・外部音源・WebGLは使用しません。システムフォントの字幅、ボタンの文字配置、陰影にはAndroidとブラウザの差があります。

成功時のAndroid ToneGenerator(25)、失敗時(26)、各160msを、Web Audioで合成する短い成功音/低い失敗音へ対応させています。AndroidのToneGeneratorそのものではなく、音色の完全一致は保証しません。音源やBGMを省略したものではありません。失敗時の100ms振動はVibration APIが使える端末だけで試みます。

タイトルの「オフライン」はブラウザ版では保証できないため「ブラウザ版」に変更。説明の「指を離すと停止」は、棒だけが止まり時間は減り続けることを明記しました。
