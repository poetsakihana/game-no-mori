# 咲華詩界 ―ことのはを旅する者― ブラウザ版

原APK 0.4.0 → **0.4.0-web.2**。ZatuPlay `collection-42`。

原APK内のWebゲームを移植しています。別のゲームへの置き換えではありません。原詩2,183篇、案内役49人と主人公、50点のSVG、5種類の風景、全10章の物語を収録。`poems.json`、`cast.js`、`story.js`、50点のSVGは原本とバイト単位で同一です。地形・分類・旅人の物語と登場人物はゲーム用の創作です。

## 遊び方

- 矢印 / WASD、画面のタップ、下の方向ボタンで移動します。Eまたは「詩碑を調べる」で調べます。
- 3つの光に近づいて言葉を集め、中央の詩碑に近づいて調べると、その詩全文を読めます。
- 近くの案内役にはEで話せます。「案内役に会いに行く」はまず近くまで歩き、もう一度押すと会話します。
- 前後の詩、詩の図鑑の検索、登場人物の「初登場の詩へ」は初めから使えます。詩に新しい解放制限を加えていません。最後の詩の次は最初に戻ります。
- お気に入り登録、本文・題名・番号の検索、登場人物の名前・役割検索も原作の機能です。
- 物語の解放条件は、読んだ異なる詩の数が **0、10、50、150、300、600、1,000、1,400、1,800、2,183**。同じ詩を繰り返し読んでも数は増えません。
- P / Escapeまたは「一時停止」で停止。「旅を再開」またはPで再開します。ダイアログ内ではEscapeはダイアログを閉じます。

## 保存と読み込み

このサイトのこのブラウザにだけ保存します。APK、別端末、別ブラウザとは同期しません。保存キーは専用の `zatuplay.sakihana-shikai.web.v1` です。

- 原作の詩番号・既読・お気に入り・各詩の3つの収集状態・会話した住人に加え、ブラウザ版では**安全な現在位置と音設定**を保存します。移動先・押しっぱなしのキー・開いたダイアログ・会話途中は復元しません。
- イベント操作時、停止時、移動中は約1秒ごとに保存。OSによる強制終了などでは最後に保存された位置まで戻る場合があります。
- Web Locksで書き込みを1タブに限定します。非対応ブラウザや2つ目のタブはメモリ内だけで遊べます。自動保存されないことを画面に明示し、JSON書き出しは使えます。別タブを閉じた後も、保存を開始するには再読み込みが必要です。
- 保存拒否・容量不足・破損・別の画面からの変更を検出すると上書きを止めます。破損した元のデータは削除・置換しません。現在の進行は「旅の記録を保存」、読み取れた元データは「保存済み記録を書き出す」で保管できます。保存障害後に途中経過を残すには、再読み込み前に書き出してください。
- 「記録を読み込む」は2MBまでのJSONを検証してから、件数と復元方法を表示します。キャンセルしても進行は置き換わりません。同じファイルを続けて選べます。遅れて読み終わった古い選択は破棄します。
- 復元を確認すると、現在の記録を `.before-import` にバックアップしてから置き換えます。バックアップ保存が失敗したら置き換えません。メモリ内モードでは復元とバックアップもメモリ内だけです。「復元前の記録を書き出す」で別ファイルに保管してください。バックアップは直前1回分です。
- 原作の通常のJSON記録も、全項目が有効なら読み込めます。原作に位置・音設定がなければ中央下・音オフから始めます。Android側の独自保存形式すべてとの互換性は保証しません。
- ダウンロードの開始と、端末にファイルが実際に保存されたことは別です。ブラウザのダウンロード一覧で確認してください。サイトデータの消去や端末変更前は必ず書き出してください。

## ブラウザ向けの変更

- Android専用の `android-save.js` とその参照を除外し、元のBlob/ファイル入力方式を検証・確認・バックアップ付きで実装しました。
- 原作の3座標単位/描画フレームを、基準60Hzと同じ**180単位/秒**に変更。30/60/120Hzで同じ歩行速度です。アニメーションも60Hz相当の時計を使います。1フレームは最大50ms（移動は最大9座標単位）として扱い、長い処理停止の経過時間は切り捨てます。極端な低FPSでは無理に追いつかず安全側に動きます。0.4.0-web.1の250msで自動停止する処理は公開Chromeで歩行を妨げたため、0.4.0-web.2では前面表示中の遅い描画を繰り返し停止しない方式に修正しました。非表示・フォーカス離脱時の停止と明示的な再開は維持しています。
- フォーカス離脱・非表示・ポインタ中断時は明示的な再開待ち。クリック移動先とキー状態を消すため、復帰直後に勝手に歩きません。ダイアログの開閉・詩の移動でも入力を消去します。
- 履歴キャッシュから戻った場合は保存ロックを再取得せずメモリ内に留め、再読み込みが必要と表示します。
- 合成音は原作の短い正弦波音です。録音音楽・読み上げ・声優音声はありません。ユーザー操作後だけ鳴り、音APIの拒否・非対応時も無音で遊べます。停止・非表示・音オフで音を止めます。
- バージョン付き素材URL、ZatuPlayへ戻るリンク、キーボードフォーカス表示、保存状態の表示を追加しました。
- 外部素材・外部ゲームサーバー・広告・トラッキング・第三者ランタイムを使用しません。初回の詩集と画像の取得には通信が必要です。このゲーム専用のService Workerはなく、**オフライン起動は保証しません**。

## 公開Chromeでの確認（2026-11-12）

対象は `0.4.0-web.2`、公開コミット `f6b85a98d02261381f40f9a90a268d039280d40b`。GitHub Pagesの同一コミットの配信成功後に、公開URLを実ブラウザの通常UIで確認しました。

- 第1～4篇をそれぞれ3つの光から通常操作で読み、第5篇の光1つまで進行。途中の光・既読・位置・音オン設定が再読み込み後も残ることを確認しました。**通常プレイで10篇を読み終えた試験ではありません。**
- 別枠の境界試験として、9篇既読の明示的なテストJSONを通常のファイル選択・復元確認から読み込みました。その後、第10篇の3つの光と詩碑は通常操作で進め、第2章「届かない手紙」の解放、第3章の50篇条件、再読み込み後の維持を確認しました。
- 境界試験後は、実際に獲得した4篇と第5篇の光1つの記録へ戻しました。同じ実記録を再度読み込むことで復元前バックアップも実記録に戻し、書き出した両方のデータが元の実記録と完全一致することを確認しました。
- 案内役ことりとの会話、お気に入りと検索、明示的な停止と再開、検索欄でのWASD入力、Escapeで閉じる操作を確認しました。人物図鑑の50項目、前後移動・端の循環・最終篇への自由な移動は同じ機能を持つweb.1で確認済みです。
- 実JSONダウンロード、復元キャンセル、同一ファイルの再選択・確認復元、バックアップのダウンロード、別タブの保存禁止と元記録の維持、ZatuPlayへの戻り先を確認しました。入力・停止試験後の実JSONも元の4篇の記録と完全一致しました。

**未確認の範囲:** 全2,183篇や10篇連続の通常手動読了、実機のタッチ操作、スマートフォン、他ブラウザ、実際の音を聴く確認、オフライン起動。非表示・フォーカス離脱、破損・容量不足などはモデル試験で検証しましたが、公開Chromeで同じ条件を実際に発生させた結果とは区別しています。
