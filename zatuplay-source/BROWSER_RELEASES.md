# ブラウザ公開カタログ

配信ファイル: `zatuplay/data/browser-catalog.json`
ソース保存用: `zatuplay-source/public/data/browser-catalog.json`

APKカタログと独立して管理します。自動APK同期で上書きしないでください。

```json
{
  "schemaVersion": 1,
  "updatedAt": null,
  "apps": []
}
```

公開する作品ごとに `apps` に次の情報を追加します。

- `id`: APKカタログにある作品の正確なID。
- `url`: 一般公開され、実際にブラウザで起動確認したHTTPS URL。相対URLは `/game-no-mori/zatuplay/` を基点に解決します。
- `version`: ブラウザ版のバージョン。APKと同じとは限りません。
- `checkedAt`: 起動確認日時（ISO 8601）。
- `note`: 任意。ブラウザ版の制限、操作方法、APKとの差異など。

追加前に作品を公開する権限、一般利用者からのアクセス、画面・操作・音声・保存を確認し、未確認部分や制限を記載してください。所有者専用サイトをそのまま掲載しないでください。APKやZIPへのURLはプレイURLにできません。

カタログはページ表示時に再取得されます。コードの再ビルドは不要です。まだ一般公開と起動確認ができていない作品は配列に入れず、「対応準備中」を維持してください。
