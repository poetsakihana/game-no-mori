# ブラック先生 3 ブラウザ版

APK `60.BlackSensei3-v1.0.0.apk` (1.0.0) の Web 資産を基にしたブラウザ版 1.0.0-web.1。全50章250面。外部ライブラリやゲームサーバーは不要です。

## 配置

このフォルダー直下の index.html、game.bundle.js、styles.css、sequel.css、browser.css、browser-bootstrap.js、front.css を `games/black-sensei-3/` へ配置します。`www/` は未変更の抽出原本で、公開には不要です。一覧リンクは `../../browser/`。

## 変更

Android 固定画面 CSS と専用起動処理を、元のレスポンシブ画面・互換処理に置換。一覧リンクとブラウザ保存の注意を追加。停止中やフォーカス中のキー入力、Escape長押し、物語中の長押しによる連続送り、停止中のタッチ入力を抑制。不正な保存スコアを除外。ゲーム内容と各面のロジックは維持しています。

## 保存と音

保存キーは `black-sensei-3-v1`。同じサイトでも他作品と分離されます。APK と自動同期せず、端末間同期やセーブ書出し機能はありません。サイトデータの削除やプライベートモードで失われる場合があります。音は初期OFF、♪から有効にする Web Audio 合成音です。ネイティブ専用機能は残っていません。

## 検証

`node browser-game-next/tests/black-sensei.cjs`。II/III合計35件の Node VM ロジックテストが成功。各250面の生成、出口/ボスのクリア判定、解放・保存、物語遷移、入力・停止・再開、保存破損/保存不能、IIIの陸海空訓練を確認。DOM/Canvasはモックであり、実ブラウザでの操作や全250面の手動完走ではありません。JavaScript構文・ローカル参照の存在も確認。

実画面、スマホ実機、Safari/Firefox、音の実聴取はこの段階では未検証。公開後のChrome操作確認が必要です。
