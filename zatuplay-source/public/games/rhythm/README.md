## 起動と操作

HTTP(S)で `index.html` を配信します。上部の相対リンク `../../browser/` でZatuPlayのブラウザ一覧へ戻れます。

- Space / J / Z: A。K / X / 下矢印: B。左矢印 / F: 左。右矢印 / L: 右。H: 左＋A同時。
- 画面内の方向・A/Bボタンはタッチにも対応。通常ステージの「練習する」ではY長押しでお手本を表示。
- 各ステージの紹介とガイドに操作を表示。ドラムは専用キー表、ビートスペルは魔法選択と詠唱入力を使います。
- Escapeまたは上部「一時停止」で停止。「続きから再開」の3秒後に再開します。
- 初回は1-1「輪くぐり」。65点以上で次のステージ、90点以上でメダルを獲得します。元の「全解放」スイッチも保持します。通常の解放・保存確認ではOFFにしてください。
- パーフェクトキャンペーン、3連続パーフェクトによるナイトモード、採点窓（68/125/185ms）、難易度・譜面・報酬は元のままです。

## 保存と通信

原本の `rhythm-*` localStorageキーを保持します。最高点・クリア解放、パーフェクト記録、ランクとミッション、リング、各サブモードの記録、音読・音量・入力補正などを保存します。オトボードの作曲は「保存」を押した時に保存。**演奏・バトル・神経衰弱等のプレイ途中は保存しません**。中断中にページを閉じた場合も途中からは再開できません。

APK・別端末・別ブラウザとは同期しません。サイトデータの削除、保存禁止、プライベート閲覧、容量不足では記録を失う場合があります。上部の保存状態を確認してください。同じゲームは1タブで遊んでください。

壊れたJSONや不正な型・範囲を起動時に検出した場合、元データを変更せず、そのタブからの保存を止めます。自動削除・初期データによる上書きはしません。保存領域の取得・読込・書込失敗と別タブ競合でも、明確な通知を残してタブ内でのプレイを続けます。保存失敗後の新しい成績を保存済みとは表示しません。複数キーの保存途中で失敗した場合、失敗前に書き込めた記録だけが残る場合があります。

初回起動・再読込には通信が必要です。読み込んだ後のゲーム処理は端末内ですが、サービスワーカーによるオフライン再起動を保証しません。外部CDN・ゲームAPI・オンライン対戦はなく、「みんなで遊ぶ」の相手はCPUです。元の独自合成音を保持し、公式音源は同梱しません。掛け声・音読はブラウザ/OSの日本語音声を使い、音声サービスによって通信する場合があります。音声の有無や遅延は環境依存です。画像差し替えは端末内で読み込み、再読込すると元に戻ります。

## 中断の扱いとブラウザ修正

- 原本ではblur/非表示でメインゲームが中止され、パーフェクト挑戦も失敗として消費されていました。サブゲームも消えて操作不能になり得ました。ブラウザ版は状態を保持して停止し、戻っただけでは再開しません。
- 非表示・blur・pagehide、AudioContextの停止、700msを超える画面更新停止を検出します。元のRAF、譜面時計、遅延コールバックを止め、入力と音声キューを解除します。
- 再開時は明示操作と3秒の準備後に音声経路を作り直します。基準時計・クイズ時計・神経衰弱ロックも一緒にずらし、停止中の時間をミス・攻撃・挑戦回数に算入しません。準備中に再び離れた場合、再開は取り消されます。
- 長押し途中の入力だけは安全に解除してその合図から再挑戦します。それより前に採点済みの入力・得点は保持。新しい入力で長押しとリリースを行います。
- 一時停止画面から「中断を取り消して一覧へ」を選ぶ場合は成績を付けません。一方、ゲーム内の通常「中止」は原本どおり挑戦失敗になる場合があります。
- 原本の「おやつ」で無入力のまま時間切れになった際に結果へ進めない不具合を修正。古いパーティー終了タイマーが新しいゲームを終了させないよう所有者を確認します。
- ドラムのSpace/J等が汎用サブゲーム処理と専用処理で二重入力される問題を修正。フォーム入力と通常ボタンのキーボード操作をゲーム入力から区別します。
- 音声開始失敗、開始待ちでの画面離脱、再開失敗を回復可能にします。元の音量に加え、掛け声ON/OFFも保存し、全体音量を読み上げにも適用します。
- 横向きAPK専用レイアウトを通常ページに直し、画面内のコントローラー、44px方向ボタン、タッチ中断、スクロールできる設定/メニュー、キーボードフォーカスを追加します。

### 通常のミニゲーム完走・保存/解放の確認

1. 「はじめる」→「モード」→「みんなで遊ぶ」→「リズム神経衰弱」の「本番」。レベル1・全解放OFFのままで最初から遊べます。

4. 一時停止・タブ切替後に自動再開しないこと、再開までの3秒と成績維持、上部一覧リンク、音量/掛け声設定の再読込も確認してください。
