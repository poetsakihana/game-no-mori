## 変更

保存キーは `black-sensei-2-v1`。同じサイトでも他作品と分離されます。APK と自動同期せず、端末間同期やセーブ書出し機能はありません。サイトデータの削除やプライベートモードで失われる場合があります。音は初期OFF、♪から有効にする Web Audio 合成音です。ネイティブ専用機能は残っていません。
