## ブラウザ向けの変更

- ZatuPlay一覧へ戻るリンク、端末内保存・通信・音の説明を追加。
- クリア数だけでなく、現在の問題・入力途中・ヒント・正解画面・選択ページ・音設定を保存。IME変換中のEnterを判定せず、二重正解や再挑戦の二重加点を防止。
- 保存キーは `zatuplay-riddle-king-v1`。元の `king-progress` は初回のみ読み込み、書き換えません。Android内の保存とは自動同期しません。
- JSONと全フィールドの整合を確認。破損データ、未知の版、読込拒否は元データを上書きせず、この回だけ保存なしでプレイできます。
- Web Locks内で直前の保存値を比較し、別タブの更新を上書きしません。`storage` イベントでも停止。Web Locks非対応では保存なしと明示します。書込失敗時は未保存と再試行ボタンを表示します。
- 現在の記録のJSON書出し、20KB以下の検証済みファイルからの確認付き復元。同じファイルの再選択、復元キャンセル、別タブ競合を扱います。保存保護中は復元も拒否します。
- hidden、blur、pagehideと手動停止で音・遅延音・入力を止め、ポインターキャプチャを解除。自動復帰せず再開ボタンが必要です。音ONの保存を読んでもユーザー操作までは鳴らしません。音声API非対応なら画面で知らせ、問題は続けられます。
- タイマー制限のない原作なので、停止中に問題時間が減る変更はありません。
- 初回通信が必要です。問題スクリプトだけで非圧縮5,281,451 bytesあり、低速回線での読込時間は実測していません。専用オフライン保証、クラウド同期、Android版データの自動移行はありません。

## 公開Chromeでの通常UI確認手順

入口候補: `/game-no-mori/zatuplay/games/riddle-king/?v=1.1-web.1`。公開/配信完了の証拠ではありません。

1. 未保存のブラウザで「0 / 16,000」「なぞなぞ見習い」を確認。「冒険を続ける」でパンの問題を表示。
2. 「ねこ」→「答える」で誤答。「ヒント」で「火にかけて使うよ。」。「ふらいぱん」で正解し、解説と「次のステージ」を確認。
3. 次へ進み第2問に「く」を入力して再読込。同じ問題・「く」が戻ることを確認。「くし」で正解。冒険の記録で2/16,000、ステージ選択で1・2のチェック、3の選択可、4以降のロックを確認。
4. 第3問の答えを入力途中にして一時停止→再開。別タブへ移動して戻った際も停止パネルが出て、自動復帰しないことを確認。
5. 音ON/OFFの表示と再読込保存を確認。音ONのまま再読込すると停止画面から明示再開になることを確認。実聴取の可否は別記録にする。
6. 保存説明からJSONを書き出し、ファイルを検査。通常UIで後の問題を進め、書き出したファイルを選んで置換確認をキャンセル。再び同じファイルを選び、確認して復元できることを確認。
7. 2タブで同じ進行を開き、一方で進める。もう一方の上書き停止表示と、再読込時に新しい進行が残ることを確認。
8. 代表の問題クリアは第1問で可能です。通常進行を20問まで確認する場合、下の回答表を使い、「答える」→「次のステージ」を繰り返します。20問目の正解後に第21問が現れ、冒険の記録で20/16,000、選択で1〜20のチェック・21の解放・22以降のロックを確認します。第21問にも正答して数字問題への移行と21/16,000の再読込保存を確認できます。ゲーム内部状態の書換えやテスト関数注入はしません。
9. 一覧リンク、狭い画面、キーボードフォーカス、コンソールのゲーム由来errorを確認。全項目の結果と未検証範囲を記録してからカタログ登録を判断します。
