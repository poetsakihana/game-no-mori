## ブラウザ版の修正・追加

### 中断可能な1回の精算

原作は先にBETと回転数を保存し、その後で結果を決め、アニメーション終了後に配当を保存する。途中の再読込で結果だけを失う問題があった。

この版は回転前に3つの結果を確定し、BET・速度・台・配当・回転番号を `pending` に入れ、引落し・回転数と**同じ1回のlocalStorage.setItem**で保存してから表示を回す。終了時は配当と成績を加算し、同じ保存に `pending:null` を入れる。再読込時の未精算記録はその結果のまま1回だけ精算する。精算の保存が失敗しても、直前の保存には未精算記録が残り、次回起動で同じ残高を復元できる。再乱数・二重払いはしない。

保存失敗後の続きはメモリ内だけで、再読込で未保存分は失われる。これは上部に常時表示する。保存不能時にも永続化できたと主張しない。サイトデータ削除・ブラウザやOSによるデータ喪失を防ぐ保証ではない。

- 非表示・ウィンドウのフォーカス喪失・pagehide・ヘルプ・設定で自動停止し、今の1回を即時精算する。進行中のアニメーションと古いタイマーは無効化する。復帰・設定閉じで自動再開しない。
- 台変更での自動停止は原版と同じ。BET・速度の変更と無料補充でも自動停止する点はブラウザ版の安全対策として追加した。変更後は明示的に自動スタートを押す。
- 手動回転・台・BET・速度・補充・破壊的操作は処理中に競合させない。自動停止は保存待ち中も押せる。音OFFは進行中の音も止める。
- 音声APIがない場合、例外、resumeのPromise拒否もゲームを停止させない。効果音の種類・音量・周波数・長さは原作と同じ。
- 数値は非負の安全な整数。上限付近で加算が不正確になる回転は開始前に止める。実用上のゲームルールを変更せず、記録の破損を防止する。
- 元のパネル・グラデーション・10台の色・絵文字と配当表を維持し、一覧への直接リンク `../../browser/`、バージョン表示、フォーカス表示、縮小画面用補正、動きを減らす設定対応を追加。画面拡大を禁止しない。

### 記録とJSON

- 新規キー `zatuplay:slotten:v1`、退避キー `zatuplay:slotten:v1:backup`、Web Lock `zatuplay:slotten:v1:writer`。APKの `slotten` キーは読まない・書かない・移行しない。
- 全書込みはWeb Locks内で直前の保存文字列を比較して行う。他タブの変更を検知したら新しい回転・上書きを停止し、書出しと再読込を案内。排他APIが使えない環境では安全でない代替ロックを作らず、**保存なしのメモリモード**とする。
- 壊れた保存・将来版の保存はそのまま保持する。通常プレイや「保存を再試行」では上書きしない。確認済みの読込・リセットのみ、原文の退避成功後に置き換える。書込拒否・容量不足で失敗した置き換えは現在状態を維持する。
- コイン、全成績、台、音、BET、速度、リール、直前結果、未精算結果の全項目を保存。BET・速度・リール・未精算結果・JSON・リセットはブラウザ版の追加であり、原APKの機能ではない。
- 記録JSONの形式は `zatuplay-slotten` version 1。復元は全フィールド、型、範囲、成績と回転番号の整合、未精算の配当再計算を検査する。未知フィールド・不完全JSON・不正型・不一致の配当・全階層の重複キー（Unicodeエスケープで同名のものも）を拒否。JSON構文解析は最大深度12・4,096値に制限する。通常JSONは最大32 KiB UTF-8、退避JSONは最大96 KiB、退避する原文は最大32 KiB。過大な原文や退避結果は破壊せず置き換えを中止する。
- Android JSONの独自推測・無条件取り込みはしない。任意の別作品や全localStorageを列挙する書出しはない。
- 読込・リセットは確認を取り、直前のメモリ状態と保存原文を1世代退避する。「直前の退避記録を書き出す」のJSONを読み込めば復元できる。通常の取消・失敗で現記録を変更しない。
- 同一ファイル再選択、ファイル選択取消、遅い旧読込み、新しい読込み、取消された新しい読込み、閉じる・Esc・離脱・非表示を世代番号で区別する。Web Lock待ち中の取消も書込み直前に再確認する。
- JSONは認証済みセーブや不正防止機構ではない。無料ローカルゲームの利用者管理バックアップであり、外部賞品や資産の根拠にはならない。

## 再検証のための実ブラウザQA手順


1. HTTPSまたはlocalhostでこのフォルダを開く。版表示、10台の名前・副題・絵柄・配当表を確認し、**全10台で通常の「1回まわす」を最低1回ずつ**操作する。4 BET・3速度を実際の選択欄で切り替え、1回分だけの消費と回転数を確認する。コンソール・失敗リクエストも調べる。
2. 通常の乱数で自然に当たりが出た場合に、その台・BET・絵柄・配当・残高・累計獲得・当たり回数を記録する。再読込後も同じであることを確認する。出なかった場合は「自然当たり未確認」と明記し、強制したモデル結果を自然な当たりと数えない。試行回数から当たり時刻を保証しない。
3. ゆったり速度で開始直後に再読込し、回転数・BET・結果が1回だけ精算され、再度の再読込で二重加算されないことを確認する。設定や別タブへの移動での停止、復帰後の明示的再スタートも確認する。
4. auto開始、回転中停止、終了後450ms間隔中停止、連打、台変更、ウィンドウblur、タブhidden、設定/ヘルプ、Esc、戻る・戻って来るを試す。旧タイマーで新たに回転が始まらないことを確認する。
