## Ending/reset update (web.2)
- 全50ステージを1人以上が生き残りで完了した時点で、同じversion1保存にoptional `completed:true`を記録。旧version1はそのまま読込可。50面到達だけでは完了扱いにしない。
- クリア条件を入口に明記。保存済みクリアから結末を再鑑賞可能。完了済みデータは途中再開ボタンを出さない。
- 保存済みランを新規ランで置換する前に確認し、旧原文を専用キー `.recovery` へ退避。初期化/JSON復元も確認と退避を必須にし、退避失敗時は上書きしない。退避は直前1回分なので必要なら回収して別途保管。
- 原文・前回退避の回収、前回退避本文表示、JSON復元を常設。破損時も回収/明示復元可能。保存失敗時は未保存の試行データを「読込済み進行を表示」で回収可能。別タブ占有時は復元/初期化不可。
- Web Lock/保存原文一致チェックを維持、保存失敗時は描画更新と進行を停止。離脱時に保存権を解放し、BFCache復帰は再読込。
- `node test-model.cjs`: 新規確認/退避、最終面完了と再鑑賞、ending RAF、停止ガード。
- `node test-storage.cjs`: 旧v1互換、completed、確認リセット/復元、破損回収、容量失敗、競合、ロック占有、未保存データ回収。
- 上記はNodeのmock DOM/canvas検証。今回変更の実ブラウザ操作/スマホ実機/全50面手操作完走は未検証。カタログ/公開はこの作業では未実施。
