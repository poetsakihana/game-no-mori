## ブラウザ向けの対応

- ZatuPlay一覧へ戻る同一画面リンク。原作座標上に実HTMLボタンを置き、Tab/Enterでも操作可能。
- マウス/タッチの元操作に加え、矢印/WASDと方向ボタン。通常90px/秒、Shiftは30px/秒。判定はドラッグと同じ。方向キーの斜めは速度を正規化。
- 自動保存は `zatuplay-iraira-bo-v1`。解放/BEST/音に加え、現在の画面・棒の位置・経過時間・選択ページを保存。実行途中の再読込は停止状態になり、「つづける」で明示再開。
- 約1秒ごと、および開始/停止/結果/ポインター解放/キー解放/メニュー操作の区切りで保存。中断時は入力と音を解除し、blur/hidden/pagehide後に自動で動き出さない。
- JSON全項目・型/範囲・進行の整合・コース上の位置を検証。破損/未知の版/読込拒否は元データを上書きせず、今回だけ保存なしで遊べる。
- Web Locksで保存直前の値を比較。別タブの古い保存を拒否し、storage更新/削除/全消去でも停止。保存を読み直す前に未保存分の破棄を確認。Web Locks非対応では安全のため保存しない。
- 容量不足や書込拒否を成功表示にしない。今回の画面を維持し、「保存を再試行」。JS/Canvasの読込・実行失敗は警告して保存を止める。
- ユーザー操作前は音を鳴らさず、停止/非表示で合成音を止める。音声APIが使えなくてもプレイ可能。元の短い成功/失敗音をWeb Audioで合成するため、Androidとの音色差がある。
- 初回通信が必要。オフライン、クラウド同期、Androidセーブの自動移行は非対応。ブラウザ保存の消去で進行も失われる。強制終了直前の約1秒および終了時の非同期保存は保証できない。

## 実Chromeの代表QA手順

1. 初回タイトルで「NEON MAZE」「イライラ棒」、30面表記、音ON/OFFと一覧リンクを確認。冒険をはじめる→STAGE 1、2以降LOCK、全3ページを確認。
2. STAGE 1を開始。棒は元座標(180,666)。ドラッグは相対0.8倍なので、小分けに道をなぞり、離して持ち直す。指を離しても時計が減り、停止ボタンで時計も止まることを確認。
3. 壁へ動かして「壁に当たった！」→リトライ。キーの矢印上を短く押して棒が動くこと、Shiftで遅くなること、ポインターで移動できることを確認。
4. 一時停止→つづけるを確認。途中位置で一時停止してページを再読込。位置/残り時間を保持し、自動進行せず再開ボタンが出ることを確認。
5. STAGE 1を通常入力でクリア。中心線の大きな流れは、下の中央→右側(240,550)→(225,440)→中央(180,416)→左側(135,390)→(112,300)→中央GOAL(180,166)。途中は水色の道を見てなぞる。直線の近道は壁に当たるので避ける。
6. CLEAR/BEST、次のステージ→STAGE 2、選択画面で1/2解放・3以降LOCK。再読込でも1面のBESTと2面解放を保持することを確認。
7. 別タブで同作品を開いて操作・保存。古いタブに「別のタブで保存が変わりました」、再開不可/上書き停止。読み直す取消→実行で新しい保存を保持。
8. ページ外へフォーカス/タブを切り替え、戻っても停止状態のままか確認。可能なら音を実際に聴き、表示だけで実聴済みとしない。
9. 一覧リンクで同一画面に戻る。端末横向き/狭い幅でUIの切れやスクロールを確認。
