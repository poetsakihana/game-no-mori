# エアガイツ QUEST REBORN ブラウザ版

版: **2.1.1-web.1**。カタログID: `quest-reborn`。

APK版 2.1.1 の `assets/www` に含まれるゲームを、ZatuPlayのサブディレクトリで動作するブラウザ版へ移植しました。2人の主人公、21階・7地域、100種類の通常敵、21体の階層ボス、アクション・魔法・装備・図鑑・物語と元のキービジュアルを保持しています。原作の全イベント・全アイテムを再現したものではなく、元APKと同じファンリメイクです。

- 原本APK SHA-256: `3f61c1fe7d2aa4351efed09af62dcc573d5ab99f658bbd1dfcf9192a872dc06e`
- `SOURCE_ASSETS.json`: 原本のファイルハッシュ、無変更の資産、移植時の変更・除外を記録。
- Three.js r170 と原本のMITライセンス通知 `THIRD_PARTY_NOTICES.txt` を同梱。
- 原本APK、Androidコード、署名鍵、秘密情報は公開ファイルに含めていません。

## 起動と操作

HTTP(S)配信で `index.html` を開きます。相対パスのES modulesと同梱のThree.jsを使用し、外部CDN・外部フォント・ゲーム用APIへ接続しません。`file://` での直接起動は想定しません。**WebGL 2対応の最新ブラウザ**が必要です。3Dの初期化は新規開始・続きからの選択時に行います。

- WASD / 矢印: 移動
- J: 連撃、K: 魔法、Space: 回避、L: ジャンプ、Shift: 防御
- H: ポーション、1 / 2 / 3: 魔法切替、E: 宝箱・階段・帰還の門を調べる
- Tab: 装備・図鑑、Escape: メニュー / 閉じる
- 狭い画面・タッチ対応端末: 画面のスティックとアクションボタン

タイトルと一時停止メニューからZatuPlayのブラウザ一覧へ戻れます。

## ブラウザ向け変更

- Android専用クラス・CSS・バンドルの入口を使用せず、元の `game.js` → `models.js` / `core.js` → ローカル `vendor/three.module.js` / `catalog.js` を読み込みます。重複する `game.bundle.js` は配信しません。元のデータ・モデル・CSS・画像・Three.jsは無変更です。
- 起動失敗時はWebGL 2とブラウザ向けの復旧案内を表示。Android System WebView更新の案内と、起動ごとに描画品質を軽量へ上書きする処理を除去。
- localStorageの取得自体が拒否される場合、容量不足、壊れたJSON・不正な型でもゲーム全体が停止しないよう保護。保存失敗は常時見える注意と一時停止メニューに表示し、成功したと偽らないよう変更。
- 不正なセーブは勝手に削除せず、新しい冒険を明示的に確認した場合にだけ上書き。旧カタログのセーブ移行を維持。範囲外の位置は安全な入口へ補正。
- タブ非表示・フォーカス喪失・ページ離脱時に保存と停止。キーボード・スティック・長押しを解放し、復帰だけでは自動再開しません。既に開いている図鑑・設定等は維持します。
- WebGLコンテキスト喪失時は保存・停止・案内。復帰後はメニューから明示的に再開します。WebGL初期化失敗では、選びかけの新規冒険で以前の記録を上書きしません。
- タッチのpointercancel / lostpointercaptureに対応。描画中の死亡判定後は同じフレームで敵・飛び道具が続けて更新されないよう保護。

## 保存と通信の制限

進行は元のキー `ehrgeiz-quest-reborn-v2`、設定は `ehrgeiz-quest-settings` に保存します。通常は約8秒ごと、宝箱・討伐・階層移動・メニューなどで保存します。APK・他端末・他ブラウザと自動同期しません。プライベート閲覧、保存禁止、容量不足、サイトデータ削除では記録が残らないことがあります。保存のバックアップ書出し機能はありません。

記録するのは主人公の状態、到達階、鍵、宝箱、倒した敵、装備、所持品、図鑑・進行等です。元の仕様どおり、倒していない敵の途中HP・位置や飛び道具は保存せず、再開時に再生成します。戦闘中の一瞬を完全に復元する機能ではありません。

初回起動・再読込には通信が必要です。サービスワーカーによるオフライン再起動保証はありません。読み込んだ後のゲーム処理は端末内で実行します。オンライン対戦・クラウド保存はありません。同じゲームを複数タブで同時に遊ぶと保存を上書きし合うため、1タブで使用してください。

## 自動検証

実行:

```sh
node zatuplay-source/scripts/test-quest-reborn.cjs
cd zatuplay-source && npm run build
```

`test-quest-reborn.cjs` / `quest-harness.cjs` はNode VMと模擬DOM・模擬WebGLRendererで、実際のゲーム・Three.jsのシーン・元のモデルを動かすロジックテストです。

- 100通常敵・21ボス・7地域・20体形、全21階の出現テーブルと全100種類の出現範囲。
- 21階 × 60シード = 1,260迷宮で、すべての床と7部屋が入口から到達可能なこと。
- 元の121敵モデルと両主人公の生成・アニメーション、全21階の3Dシーン構築、衝突・方向・攻撃範囲。
- 両主人公の開始、キーボード移動・跳躍・回避・回復・魔法、宝箱の一度きり報酬、帰還の門の補給・鍛冶・休息。
- ボス撃破による鍵・図鑑・経験値・レベル、B1→B2保存・再開、鍵がなければ階段を使えないこと、全21階の守護者を順に倒した後のエンディングと再読込。
- 死亡再開の20%所持金減少が一度だけであること、装備・鍵の維持。
- 保存拒否・容量不足・不正JSON・不正データ・旧カタログ移行、設定保存、WebGL開始失敗時の旧セーブ保護。
- 非表示・blur・pagehide・タッチ中断、メニューを保った停止、WebGL喪失・復帰時の手動再開。
- 相対参照・ローカル依存関係、原本資産のSHA-256、ソースと配信ディレクトリの完全一致。

全階層進行の自動テストはテスト用の大きなダメージ値でボスを倒しています。実際の操作で全階層を攻略した証拠ではありません。
