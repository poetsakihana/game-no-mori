## 素材と表示の差
原本の `6boss.png` は原作の選択画面に見える画像で、戦闘のボス切抜きにも使用されています。独立の利用許諾を確認できないためブラウザ版には同梱せず、画像参照も削除。選択はCSSの色付き図形、ボスは原コードのfallback `robot(...)` を採用。ボス外観は変わりますが攻撃・HP・弱点・武器仕様は保持。非公式・CAPCOM無関係と素材除外を入口へ表示。公式再現や権利許諾済みという保証ではありません。

## 保存と操作
専用キー `zatuplay-rockman-re-v1` に撃破ボス・城進行・エンディング・音設定を保存。旧 `blueMission1`、APK、他サイトは読まず変更せず自動同期しません。元の実導線どおり、死亡時はその面の最初から。途中位置・HP・武器エネルギー・一時チェックポイントは再読込で失われます。未使用retry関数は残し、誤ったチェックポイント再挑戦説明を訂正。
Web Locks排他、未対応/破損/未知版/不正進行/読書き失敗/競合時は上書きせず停止。回収・JSON書出し・確認付き復元/初期化を追加。音初期OFF、2つの音ボタンを同期して設定保存。非表示/blur/pagehideで入力解放・音停止。停止中は保存しません。
