## Browser changes and persistence

- Native `entrance13.settings` is never read/written. One isolated record `zatuplay:entrance:1` contains validated settings, one hallway-start checkpoint and one previous replacement state. No account/network/media upload/service worker. APK and other devices do not synchronize.
- **New minimal progress save:** the original saved settings only. This browser port stores stage, anomaly, round, remaining anomaly bag and playing/won/lost state after each settled decision. Resume begins at the same hallway's entrance (x=0,z=5); walking position, elapsed walking time, NPC position, footsteps and camera orientation are not stored. Resume neither rerolls the anomaly nor grants advancement. Winning/loss remains recorded but does not resume an ended run. The title preview itself is not the saved corridor; use “保存・一覧 → 通路から再開”.
- The page holds an exclusive Web Lock. Other tabs and Web Locks-unavailable browsers run explicitly memory-only. Exact stored-byte comparison and storage events reject stale overwrites. Closing another tab does not transfer ownership; reload the desired tab. Quota failure preserves old durable bytes while latest state stays in memory for JSON export. A corrupt/unreadable original is never overwritten; it can be exported and gameplay/restore/reset remain memory-only. There is no automatic destructive repair.
- Real file import is bounded at32KiB, format/version/state validated and asks before replacement. Unknown fields, out-of-range settings, invalid/duplicate anomaly bag entries and impossible final-hall state are rejected. Export is a local JSON download. Import, reset and new run retain one previous state; “置換前に戻す” swaps it back. Subsequent replacements replace that one recovery generation. Raw export keeps original bytes, not an automatically repairable standard backup. JSON has no user identities/audio/images.
- On blur/hidden/pagehide/menu, held inputs reset, audio suspends and a pending hallway decision is settled **once** before pausing/checkpointing. Canceled timers cannot apply twice after resume/import/new run. Pagehide releases ownership; back-forward-cache return is memory-only until reload. File reads canceled by newer navigation/actions cannot overwrite them. Original pointer-cancel/lost-capture handling is retained.
- Start no longer automatically requests fullscreen or orientation lock. Browser zoom remains available. Existing landscape recommendation/light-mode control remains. Direct same-tab browser-list link and accessible status controls are added. Runtime debug-state injection API is not published. Content Security Policy prevents external connections. The original game content is not shortened.
