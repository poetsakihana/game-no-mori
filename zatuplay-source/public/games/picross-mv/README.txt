ピクロス MV移植試作 v0.1.0

重要：原作全編の完全変換版ではありません。
2003のイベントから55面の正解盤面を抽出し、公開MVコアスクリプト上で動くゲームとして再構築した部分移植版です。
原作の113マップ・イベントをすべてMVの標準イベント命令に変換したものではありません。

同梱・提供物
PicrossMV-v0.1.0.apk : Android 8.0以上用。オフライン対応、署名済み試作アプリ。
PicrossMV-project-v0.1.0.zip : MVで開くGame.rpgprojectとゲーム一式。
zip内migration/original-events.json : 原作113マップのイベント抽出記録。MVで実行できる形式ではありません。
zip内migration/report.json : 移植状況。
zip内tools : 今回の盤面抽出用Pythonソース。

プレイ方法
盤面一覧から選び、数字を頼りに塗ります。「× 印」で空白の目印。右クリックも×印。
数字の間には空白が1マス以上必要です。正解盤面と一致するとクリア。
途中経過、クリア記録は端末内に自動保存。アプリ削除・データ消去で失われます。
大きい盤面は縮小・拡大、スクロールを使用します。
同じ絵柄の別マップも原作マップ番号を区別して収録しています。
やり直す：現在の途中経過のみ消去。クリア履歴は残ります。

MVでの編集
解凍してGame.rpgprojectを開き、テストプレイ。
実行にはjs/plugins/PicrossPort.jsとjs/puzzles.jsを使用します。
標準タイトル・マップ画面の代わりに専用シーンを起動します。
各data/MapXXX.jsonのマスイベントは正解・原作座標を保存した編集参照用データです。
標準マップ上で原作ゲームを再現するイベントではありません。
実際に問題内容を変更する場合はjs/puzzles.jsのgridを編集してください。
MVコアはMITライセンスの公開community版です。MV_CORE_LICENSE.txtを同梱。
