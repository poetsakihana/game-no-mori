## 起動・操作

HTTP(S)で `index.html` を配信。上部の `../../browser/` リンクでZatuPlay一覧へ戻れます。

- 元APKと同じく55盤面はすべて最初から選べます。順番の解放制はありません。
- 「■ 塗る」で塗り、「× 印」または右クリックで空白の目印。同じマスを再入力すると消去。黒マスが正解配置と一致すればクリアし、空白すべてに×を付ける必要はありません。
- Tabで盤面へ入り、矢印キーで移動、Enter/Spaceで入力。長押しリピートは無効です。再描画後もセルのフォーカスを保持します。
- 一手戻すの履歴は現在の盤面を開いている間だけ保持。再読込や開き直し後には残りません。
- やり直すは確認後、現在の盤面と時間だけを初期化。過去のクリア履歴は残ります。
- 5×5〜35×35。大きい盤面は縦横スクロール・拡大/縮小を使用。セル幅は20〜52px。縦横のヒントをスクロール中も固定します。
- Esc/一時停止、blur、非表示、pagehideで途中の盤面を停止。復帰しただけでは再開せず「再開する」を押します。停止中の時間は加算しません。pointercancelは入力を取り消し、pointerup後の通常のタッチcapture解除は正しいクリックを妨げません。

## 保存と通信

キーは元APKと同じ `picross-mv-port-v1`。途中の塗り/×、経過秒、完成状態と全体のクリア履歴をlocalStorageに保存します。各入力、5秒ごと、一覧復帰、中断時に保存。時間は停止を除く1秒タイマーの加算で、競技用の厳密な実時間計測ではありません。

- 上部に読込済/保存中/保存成功/保存不能を表示します。保存中はページを閉じないでください。
- 不正JSON・型・ID・盤面長・セル値・時間・完成状態では元の保存を消さず、そのタブの書込を停止。自動削除・修復・初期値上書きをしません。タブ内では遊べますが保存されません。
- 保存領域getter、読込、容量・書込エラーを明示。保存失敗を成功と表示しません。最後の保存成功までが残ります。
- 書込直前の比較とstorageイベントで他タブの更新・削除を検出し、古いタブの上書きを止めます。Web Locks対応環境では同じキーの保存を排他し、待機中の最新入力を保存します。
- Web Locks非対応環境ではlocalStorageに原子的な比較更新APIがなく、完全同時の競合を完全には防げません。同じロックを使わない旧版等の書込も排他できません。**同じ作品は1タブで遊んでください。**
- ゲーム上部の一覧リンクは保存の完了を待って遷移し、保存不能なら破棄確認を表示します。保存待ち中のページ終了はbeforeunloadで確認を求めますが、ブラウザが表示しない場合があります。
- 実際のページ破棄・強制終了では非同期ロック待ちの保存完了を保証できません。pagehide/非表示時の最終保存前に破棄された場合、最後の入力やタイマーの1〜4秒を失うことがあります。無排他の書込で競合保護を回避しません。
- APK/別端末/別ブラウザとの同期、2003用Save01.lsdの引継ぎはありません。サイトデータ削除・プライベート閲覧等で記録を失うことがあります。
- 初回・再読込には通信が必要。サービスワーカーのオフライン再起動は提供しません。読込後のゲーム処理は端末内です。外部CDN、ゲームAPI、広告、分析送信、音声通信はありません。
