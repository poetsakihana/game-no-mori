# 動く城 ブラウザ版

**0.3-web.1** / 配置先 `games/moving-castle/`。

元APK「37.動く城_v0.3.apk」の `assets/index.html` にある『歩く城の冒険者 / THE WALKING CITADEL』を、ZatuPlayのブラウザ版へ移植しています。五つの大陸・50章・50ボス、物語、地形、主人公、歩行城、採集、工房、装備、戦闘と元の13点の埋込画像を保持しています。章データと13画像のバイト列は元APKと同一です。

- APK SHA-256: `852bf4d1c0364c7b0e509c010f93986645e1cb9cc763b6d3763d57b76db4a835`
- 原本HTML・章データ・画像のハッシュと変更内容: `SOURCE_ASSETS.json`
- Android本体、APK、署名情報は配信しません。
- 原本のCanvas2DとWeb Audioを使用。WebGL、外部ライブラリ、CDN、外部フォント、ゲーム用APIは不要です。

## 起動と操作

HTTP(S)で `index.html` を配信して開きます。ZatuPlayのブラウザ一覧への相対リンクを上部とメニューに用意しています。

- WASD / 矢印: 移動
- Space / J: 剣攻撃。F: 風技。Shift / K: 回避
- C: 歩行城の操縦と冒険モードを切替
- E: 採集、会話、宝箱、封印の門を調べる
- B: 工房。M: 地図。I: 持ち物。Q: 回復薬
- Escape: 一時停止 / メニューを閉じる
- タッチ端末・狭い画面: 方向パッドと攻撃・風技・回避・調べる・城切替。回復薬はメニューの「持ち物」から使用できます。

各章の守護者を倒し、城を東端の門（x=2500、y=790）へ運びます。城を降り、門の近くで E / 調べるを使うと次章に進みます。道沿いの整備士リト（x=740、y=750）は無料で主人公を回復し、城も修理します。工房はどこでも開けます。再訪は「全50章・冒険の書」から行えます。

初期資源で剣、砲台や移動脚部などを強化できます。敵の攻撃やボスの弾を避け、風技・回避・回復を活用してください。難易度、移動速度、敵の強さ、報酬、アップグレード費用は元のままです。

## ブラウザ向け変更

- 保存領域の取得拒否、容量不足、壊れたJSON、不正な数値・型を保護。成功時のみ保存回数を増やし、保存失敗は画面上部に残します。
- 壊れた保存記録は自動削除・上書きしません。「はじめから」で上書きを明示的に確認します。「つづきから」の読込失敗も新規ゲームへ置き換えません。
- タイトル / 一覧へ戻る際に保存が失敗したら、保存せず離れるか確認します。キャンセルすれば進行を保持します。
- タブ非表示、フォーカス喪失、ページ離脱で保存・一時停止・入力解除。既に開いたメニューは維持し、復帰だけでは自動再開しません。
- pointercancel / lostpointercaptureと複数タッチの識別に対応。メニューを開く際に押しっぱなしの方向入力・ボタン表示を解除します。
- 別タブから保存データが変更された場合は現在のタブの保存を止め、再読込を案内します。同じゲームは1タブで遊んでください。
- 音ON/OFFを安全に保存します。保存できない場合は現在のタブだけに適用します。
- 最終ボスの完結フラグを保存前に設定。元APKの保存順で最終章クリア済み・完結フラグなしになった記録も読み込み時に補正します。勝利画面後は同じフレームの戦闘更新を止めます。
- 未同梱の `sw.js` 登録を削除し、「オフライン対応」という保証を除去。スマホ縦・横画面、スクロール可能な長いメニュー、安全領域と44px以上のタッチボタンを追加します。

## 保存と通信の制限

進行のキーは原本と同じ `walking-castle-sakihana-v2` です。v2が存在しない場合は `walking-castle-sakihana-v1` を読めます。旧記録自体は削除せず、次の成功した保存からv2を使います。音設定は `walking-castle-muted` に保存します。

原本同様、20秒ごと、採集、討伐、購入、章移動等に自動保存します。上部の「保存」から手動保存もできます。位置、HP、資源、装備、到達章、倒したボス、採集済み素材等を記録します。未討伐の敵の途中HP・位置や飛び道具は保存せず、再開時に再生成します。章再訪時の回復等も原本の仕様です。

APK、別端末、別ブラウザとは自動同期しません。保存禁止、プライベート閲覧、空き容量不足、サイトデータ削除では進行が失われることがあります。セーブのインポート機能はありません。ページを閉じる前に「保存済み」を確認してください。

初回起動・再読込には通信が必要です。読み込んだ後のゲーム処理は端末内で動きますが、サービスワーカーによるオフライン再起動は保証しません。オンライン対戦やクラウド保存はありません。

## 自動検証

```sh
node zatuplay-source/scripts/test-moving-castle.cjs
cd zatuplay-source && npm run build
```

テストはNode VM、最小限のDOM代替と **@napi-rs/canvas 0.1.100 の実Canvas2D** を使います。Canvasパッケージが解決できる検証環境が必要です。ゲームの内部関数へのアクセスはテスト時にメモリ上で追加し、公開ファイルに変更用テストフックは含めていません。

- 元の13画像、50章の完全一致とsource / 配信ディレクトリの完全一致。
- 実画像のデコードと、タイトル・全50章のCanvas2D描画。元の地形・キャラクター・城・各ボスの描画関数を使用。
- 初回開始、移動、剣、風技、回避、城切替、回復薬、採集 / 宝箱の一度だけの報酬、無料回復、工房の費用・強化上限。
- 50章すべての未討伐時の門ロック、ボス報酬、城が遠い場合の門ロック、城を連れた章移動、最後のエンディングと即時保存・再開、再訪。
- 保存・再読込・20秒保存、v1移行、最終完結フラグの補正、不正セーブ保護、保存禁止・容量不足、保存失敗後のタイトル移動キャンセル。
- 非表示 / blur / pagehide、メニューを保った停止、タッチ中断、押しっぱなし解除、保存 / 音ボタンにフォーカスがあっても移動できること、音設定保持、複数タブ競合。
- 元の死亡ペナルティ、各メニュー、解放前の章への移動禁止。

全章進行の自動検証はテスト用の大きなダメージでボスを倒します。通常操作で50章を攻略した証拠ではありません。テスト用のCanvas資源は各章後に解放し、長時間のバッチ検証のメモリ使用量を抑えています。
