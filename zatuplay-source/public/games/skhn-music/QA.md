# Actual browser acceptance recipe (not yet executed)

Use a disposable site origin/profile with adequate storage, real file input, and the supplied owned fixtures. Do not use personal/licensed songs. Record browser/version, URL/build, date, checks and observations. Do not equate JavaScript model tests with media decode or speaker listening.

1. Fresh page shows empty library, branding, all original transport/filter/edit controls, storage limits and direct `../../browser/` return. Verify narrow portrait, keyboard focus, dialog Escape/cancel, readable error text, disabled import if IndexedDB denied. No remote song requests.
2. Pick then cancel: library unchanged. Pick `owned-a.wav`: added 1; select same file again: duplicate 1. Pick matching `owned-a.skhn`: duplicate 1. Import `owned-mixed.zip`: one new B, one duplicate A, one skipped TXT. Two tracks. Hash-broken SKHN and malformed ZIP show failures and do not remove existing tracks. Cancel during multiple import: completed files retained, no partial new record. Reload during pending import, reopen, confirm all committed records still have matching Blobs.
3. Play A from a genuine click. Verify finite duration around 6 seconds and actual HTMLMediaElement.currentTime advancing. Pause then wait at least 1 second: currentTime frozen. Seek toward middle: actual time changes. Resume until real `ended`: B starts with around 7 seconds duration. Enable single repeat: same track genuinely ends/restarts. Disable repeat, enable shuffle: two tracks always switch to the other. Rapid A/B/A switching, pause during load, page leave/reopen: no stale track/callback or extra audio. Decode failure uses saved invalid audio bytes and shows error, never substitutes a tone.
4. Search title, filter genre, comma-separated playlists: list, previous/next and ended obey visible tracks. Edit a genre and two playlists, cancel other edits and Escape: no changes. Reload confirms saved metadata and playable original Blobs; playhead/shuffle/repeat reset. Download SKHN and audio copies; compare SHA to imported fixture, reimport to confirm duplicate. Copy intentionally excludes genre/playlists.
5. Open two real tabs. Concurrently import A: one addition, one duplicate. Open same edit dialog in both: save first, then save stale second; explicit conflict, no lost first change. Focus refresh updates other tab. Simulate quota/denied storage only in disposable profile: failed insertion/edit keeps previous records and media; corrupt a test catalog entry: reported, no automatic clear. Do not erase genuine user data.
6. Native duration/currentTime/seek/ended and persistence evidence is separate from audible listening. Record speaker audition as verified only if genuinely heard. If unavailable, say “real media behavior verified; audible listening unverified.” Registration/deployment is coordinator's separate decision after this QA, not implied by a rendered empty page.
