# わらい座: 初優勝の結末 / 保存保護候補

未公開の実装候補。実ブラウザは下記の範囲で確認済み。スマホ実機・実音声は未確認。既存150人・演目・CPU・大会・CSV機能は維持。

- 初回の大会優勝で「第一章 完」。全芸人・全演目制覇ではない。既存の正当な芸人IDの優勝記録1以上でも設定から再鑑賞でき、再鑑賞は報酬なし。
- warai150-v1 のキーと既存スキーマを保持。新規時のみ音OFF。旧設定は保持。導入CSVの warai150-imported-v1 は別保存のまま。
- Web Locks排他を全ゲームscriptの前に取得。対応外・別タブ・破損・保存例外・競合では保護停止。初期化して上書きせず、起動原文と変更前退避をJSON回収可能。
- reset/importは確認後、warai150-v1.before-changeへ旧原文を退避したことを確認してから主保存を置換。失敗時はreloadしない。リセットは導入CSVを消さない。退避は直近1回分。
- 保存されない大会途中、公演途中は従来通り。別端末へはJSON手動移行。旧履歴フィールドを読み込み時に黙って削除しない。
- 離脱/結末時はセリフ・字幕タイマー・聞き流し予約・拍手・笑い声を停止し、明示的再開まで進めない。

検証: node test-model.cjs。実app起動、優勝/再鑑賞、停止、破損/排他/競合、reset/importの取消・退避失敗・書込失敗をVMのDOM/audioモックで確認。このモデル検証は人間による全台本確認を意味しません。公開は別担当。
