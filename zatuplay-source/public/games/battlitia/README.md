# バトリティア ブラウザ版

版: 1.1-web.1。元の `27.Battlitia-v1.1.apk` に同梱されたカードゲームの移植です。ソリティア・タイムアタック・100ステージのクエスト、15種類の設定と元の敵HP・攻撃ルールを維持しています。

原本SHA-256: `1812ef6f04d71435f87703774a6870f20e06cc34d638a56eabef33166888d0a4`

## ブラウザ向けの変更

- 単一HTMLのCSSとJavaScriptを分離。先頭に残っていた壊れたフォント指定を除去し、日本語のシステムフォントを使用。
- ZatuPlayへ戻るリンクと保存対象の説明を追加。元の保存キー `battlitia-v1` を保持。
- 敵へのダメージ、解放ステージ、タイムアタックの自己記録、設定を保存。元の仕様に合わせ、配札の途中は保存しない。APK・別端末とは自動同期しない。
- 保存領域が使えないときの起動停止を防ぎ、保存不能を表示。不正なセーブのコンテナ・設定値を読み捨て、旧HPルールからの移行を維持。
- 組札の移動先をキーボード操作できるよう、ラベルとEnter/Space操作を追加。

## 検証

ローカルChromeでタイトル、クエスト1面起動、山札24→23枚、戻す操作、ヒント、A♦の組札への移動、再読込後の効果音OFF・テーマ設定の保存を確認。

`node scripts/test-browser-batch.cjs` はNode VMとモックDOMのロジックテスト。52枚の一意性、正当/不正な移動、敵へのダメージと再配札での保持、勝利時の次面解放、旧HP移行、保存不能・不正セーブでの起動を確認。勝利・攻撃のテストには盤面とHPの固定テスト値を使うため、手動でのクエストクリアではありません。

クエストの手動クリア、全100面の通しプレイ、スマホ実機、Safari/Firefox、音の実聴取は未確認。公開URLでの確認日はBROWSER_RELEASES.mdとカタログのcheckedAtを参照。
