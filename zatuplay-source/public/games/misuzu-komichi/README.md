# みすゞことばの小道 / ことばの小径 ブラウザ版

ブラウザ版 **0.2-web.1**。ZatuPlay `collection-41`。完成済みAndroid版0.2の `assets/www` を直接移植しています。代替ゲームではありません。原本APK・抽出原本は変更しません。

## 原本の内容

- 提供資料の516作品・530表記。詩の本文・題名・よみ・巻表記・全バリアントのメタデータを保持。`poems.json` と4点のSVGは原本と同一バイト列です。
- 12章 × 43作品、36会話イベント × 2選択肢。主人公「旅人」、しおり・すず・あかりの原画と会話、探索風景、道しるべ、図鑑、お気に入り、3種類の目線を保持。
- 全12章は最初から選べます。章の順序を強制する新しいロックはありません。全516作品の灯りを記録すると原本の完成画面を表示します。
- 出会いの選択肢は元の会話文と記録を保持し、各章の1・22・43番目の詩へ道しるべを付けます。目線は灯りを記録したときに保存します。

**資料について:** 提供資料「KanekoPoems.xlsx」の詩文欄です。全文かどうかは未確認で、転記や異体字を校訂した版ではありません。資料の続きの行を連結し、`/` を改行として表示します。括弧内には資料作成者の検索用追記も含まれます。章、風景、問い、登場人物と会話はこのゲームの創作で、金子みすゞ本人の発言や解説ではありません。

## ブラウザ移植の変更

- 専用キー `zatuplay:misuzu-komichi:v1`。元の `misuzu-komichi-v1` および他作品の保存を自動で読書きしません。Androidの `misuzu-v1` JSONは利用者が選んだファイルだけ復元します。
- 保存はWeb Locksの排他区間で元の保存バイト列を比較してから書込みます。別タブが保存を更新した場合は上書きを停止し、メモリ内の記録と書出し機能を残します。Web Locksがない場合は危険な疑似ロックを使わず、保存はメモリ内だけです。
- インポートの全フィールド、範囲、重複ID、目線、会話選択を検査し、確認後にだけ変更。元APKで復元されなかった章・位置・音・道しるべも含め、全状態を復元します。部分的な黙示修復はしません。旧版に存在しなかった任意のイベント欄・道しるべだけ空値を補います。
- 保存変更は直前のメモリと元の保存バイト列を専用backupキーへ退避してから行います。退避または保存に失敗すると現在の状態を変えません。壊れた・未来版の保存を自動初期化せず、原データの書出しと確認付き復元を提供します。
- メモリ内だけの環境では、その旨を確認に表示して復元し、直前の状態もメモリ内に退避します。設定から退避JSONを書き出せます。そのファイルを読み込むと直前のメモリ状態を復元します。壊れた原データも退避JSON内のrawとしてそのまま保持します。
- ファイル読込に世代番号を付け、新しい選択・取消・画面移動・非表示・pagehideの後に完了した古い読込は、確認表示も書込みもしません。確認済みでもWeb Lock待ち中に閉じる・画面移動・離脱した復元は中止し、後から新しい画面を閉じません。
- インポート取消・失敗後も同じファイルを再選択できます。リセットは原版と同様、灯り・お気に入り・目線・会話・道しるべだけ消し、章・位置・音は保持します。確認と退避が必須です。
- 明示的一時停止と再開を追加。blur・非表示・pagehideで移動目標、キー、開始イベント予約を消し、音を止めます。復帰後は自動で歩かず、利用者が再開します。モーダル表示時も移動を解除。Escape長押しによる停止・再開の反復や、キーリピートによる再開閉、入力欄操作、pointercancel・lostpointercaptureによる押しっぱなしを防ぎます。Canvasのタップ移動や方向ボタンのpointercancelでは移動目標も消して一時停止し、明示再開するまで動きません。
- 原本はすでにdelta時間を使う170世界単位/秒の移動です。この速度と最大50msの更新幅を保持。高リフレッシュレート用の速度変更は必要ありません。
- 版本付きJS/CSS/SVG URL、ZatuPlayへの戻りリンク、保存状態表示、狭幅レイアウト、キーボードフォーカスを追加。AndroidのNativeFiles呼出しは除き、ブラウザのJSONダウンロードを使用。

## 音、通信、保存の注意

音は原本の短い合成環境音だけです。録音音楽、朗読、オンライン音源はありません。初回ページ読込には通信が必要。読込後の探索・詩文・画像に外部APIやネットワークは不要ですが、専用service workerはなく、オフラインでの再起動は保証しません。サイト全体のPWAキャッシュ状況によっても変わります。

保存は同じ端末・ブラウザ・サイト内だけで、同期しません。プライベートモード、容量不足、ブラウザ設定、サイトデータ削除で失われる場合があります。定期保存は4秒ごとと操作時です。強制終了・電源断では最後の非同期書込みが完了しない場合があります。重要な記録はJSONでも保存してください。図鑑の検索文字、現在のモーダル、会話の途中ページ、最後に選択中の目線は原本同様に永続化しません。記録済みの目線・会話選択は永続化します。

## 原本と整合性

`provenance.json` に原本APKと全7ファイルのサイズ・SHA-256、`content-manifest.json` に原本由来の件数・章境界と詩文全データのハッシュを記録しています。署名、DEX、ネイティブラッパー、非公開ID、秘密鍵は配布しません。`CHECKSUMS.sha256` はこの公開ディレクトリ全ファイル（checksum自身を除く）を対象とします。

リポジトリ直下で `node zatuplay-source/scripts/sync-misuzu-komichi.cjs` を実行すると、この作品だけのchecksumと `zatuplay/games/misuzu-komichi` ミラーを同期します。共有カタログ、ロードマップ、他作品は変更しません。
