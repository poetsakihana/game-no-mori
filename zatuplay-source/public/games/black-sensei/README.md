- 全50章250面。左右移動、Space ジャンプ、Z 攻撃、X 防御、E 拾う、C 必殺、Esc 一時停止。画面ボタンにも対応。

## ブラウザ向けの変更

Android 専用の全画面固定CSSを除外し、元のレスポンシブWeb画面を使用。ZatuPlay一覧へのリンク、保存の注意事項、画面ボタンの入力範囲を追加。停止中のSpaceによるボタン操作とEscape長押しを修正。不正な保存スコアを読み捨て、保存不能時も遊べるようにした。
