# DoragonOut ブラウザ版

バージョン: 2.5.2-web.1
原本: ユーザー提供の DoragonOut.apk（初代、v2.5.2 InstallFix）。
DoragonOut2 / 3 / EX4 や新3D版への置き換えではありません。

## 遊び方

- 最初は Disk 1。OPは「物語へ進む」で飛ばせます。
- ゲーム画面の「スタート」を押すと本編を読み込みます。
- PC: 矢印キーで移動、Enter/Zで決定、Esc/Xで戻る・メニュー。
- スマホ: 画面の十字ボタン、Aで決定、Bでメニュー。
- ゲーム内で「セーブ」した後、上部の「冒険の記録」へ戻ります。
- 「セーブ・引き継ぎ」から .lsd / 全体JSONを書き出せます。
- 次のDiskには前のDiskの章末セーブを使います。元の記録は保持します。
- RE:CHRONICLEは同梱されていた別の再構成版です。原作マップ版とは
  保存領域が異なります。原作マップ版が本ページの主な入口です。

## ブラウザ版の相違点

原作3Diskの741マップと6個のデータベース／マップツリーは、元APKと
SHA-256で一致しています。マップ配置、会話、イベント、戦闘データを
変更していません。原本APK自体は変更していません。

市販曲を含む元のMP3と権利未確認の追加BGMは公開コピーから除き、
該当BGMの参照先を無音OGGにしています。RPGツクールのBGM・効果音と
原作の会話音声は残しています。一部の他作品由来・権利未確認の画像を、
同梱されていたRPGツクール素材へ差し替えています。その場面では原作と
音・見た目が異なります。変更一覧は browser-port-report.json に記録。

素材の利用案内とエンジンのソース／ライセンスは THIRD_PARTY_NOTICES.txt。
素材をゲームから抜き出して再利用・再配布することは認めていません。

新デザインの顔・魔物画像を選んだ場合だけ、32bit画像を表示するための
EasyRPG拡張オプションを有効にします。原作ドット絵モードでは有効にしません。

OP/ED動画は720pのまま軽量化しています（映像H.264 CRF28、音声は再圧縮なし、各300秒）。

ブラウザではAndroidファイルブリッジを使用しません。既存のZatuPlay
PWA内で開き、独立したPWAやService Workerは登録しません。
保存データベースに固有名を付け、他作品の保存と分離しています。

## 保存と通信

起動・画像・音声の読み込みには通信が必要です。ゲーム全体の完全な
オフライン利用は保証していません。保存は端末とブラウザのプロファイル、
サイトのURLに紐づきます。APKや別端末とは自動同期しません。
同じ作品を複数のタブで同時に操作しないでください。
プライベートモード、サイトデータ消去、容量不足で保存できない／失われる
場合があります。定期的に手元へバックアップを書き出してください。

## 原作から引き継ぐ注意

原作の冒頭には、戦闘中の技によって強制終了する場合があるため、
戦闘前にセーブするよう勧める制作者の注意書きがあります。
ブラウザ版でその停止を再現したという意味ではありません。
本編全体やすべての技の通し試験は未実施です。
