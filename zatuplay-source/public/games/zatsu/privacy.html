ザツワールド ～ザツ物語～ プライバシーポリシー（公開候補）

最終更新：2026年10月25日

1. ゲームの記録

ステージ進行、所持コイン・ハート、獲得キャラクター、ランキング記録、設定を端末・ブラウザの保存領域（localStorageやIndexedDB等）に保存します。ゲーム本体に独自の外部送信機能はありません。

2. 個人情報・広告・課金

この公開候補版には、アカウント登録、広告SDK、アプリ内課金、位置情報取得、分析SDK、個人情報をサーバーへ送る機能は実装されていません。ランキングは実ユーザーとのオンライン競争ではなく、固定CPUデータとの比較です。

3. ホスティングと外部サービス

GitHub Pagesなどの配信サービスを利用する場合、配信サービス側に通常のアクセスログが残ることがあります。配信事業者による取り扱いについては、その事業者のポリシーを参照してください。

4. データの削除

ゲーム内の「セーブデータを初期化」機能で進行状況を初期化できます。ブラウザのサイトデータを消去した場合にも記録が失われます。端末間の自動同期・復旧機能はありません。

5. 変更

機能を追加する際にデータの取り扱いが変わった場合、このページを更新し、必要な説明を追加します。

6. お問い合わせ

運営者：咲華。正式公開前に、利用者が連絡できる問い合わせ先メールアドレス等を追記する必要があります。
