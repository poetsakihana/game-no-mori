# フライフレンズ / FryFriends ブラウザ版

**0.3.0-web.3 / collection-35**。完成済みAndroid版 **0.3.0** のオフラインDOMゲームを移植しています。代替のマッチゲームではありません。原本APKと抽出原本は変更していません。

## 保持した原作・ゲーム内容

- 全15話・105ページの原作漫画、7人の仲間と3人のゲストの切り抜き画像、計115点のWebPを**同一バイト列**で収録。元のCSSも同一バイト列です。
- 元の全15話の題名・導入・目標文・結末・キャラクター説明を `content.js` にそのまま保持。第4話の「そばで待つ」会話、図鑑、最終話の記念写真と45星のメッセージも保持。
- 6×6・7種類。上下左右とななめの同じ仲間を3個以上つなぎ、同じマスの再使用は不可。1個前に戻ると1段階取り消し。異なる種類を選ぶと、そのマスから選び直す元の挙動を保持。
- 得点は `10 × 個数 × (個数 − 2)`。6個以上の連鎖は同じ個数分のきらめきを追加。列ごとに重力落下して補充し、つながる3個がない盤面は自動で並べ直し、必ず3個を用意。1回の挑戦につき、おたすけは手数を使わず3回。
- 6話の得点目標、7話の特定キャラクター目標、2話の5個以上の連鎖目標。第8話は3回、第13話は4回。全15話の数値と手数は `content-manifest.json` に記録。
- パズルは順番に解放。クリア時の残り手数が9以上で星3、5以上で星2、それ以外で星1。新しく増えた星だけ1個につき20きらめき。同じ星数の再クリアに星ボーナスはありません。
- 仲間7人はその種類をつなぐと登録。ゲストは第3・9・10話クリアで解放。30手の「とことんサクサク」は最高得点を記録。
- **原作漫画は、パズルが未解放でも最初から全15話を読めます。** 漫画の解放条件は追加していません。
- 原作漫画と、ゲーム向けのルール・点数・目標・要約を区別する説明を保持。黄金色の油温泉は架空の表現で、実際の油に入らないよう注意書きを保持。

## ブラウザ移植の追加・変更

- ZatuPlayへの戻りリンク、版番号、版付きJS/CSS/画像URL、保存状態表示、キーボードの矢印移動と狭幅の追加調整。
- 専用保存キー `zatuplay:fryfriends:v1`。元の `fryfriends.v1` や他作品のキーは読み書きしません。Android版には書出し機能がないため、Android保存を自動移行する機能はありません。
- **途中のパズル保存はブラウザ版の追加です。** 盤面36個、話番号、残り手数、得点、対象個数・7種類別の個数、長い連鎖回数、おたすけ残数、終了状態、結果の星と今回のボーナス、音の設定、ホーム／パズルの表示を保存。結果画面を再読込しても報酬を再付与しません。
- 小道へ戻っても途中のパズルは保持。「途中からつづける」で再開します。別の挑戦をはじめる際は確認し、直前の記録を退避します。終了済みの挑戦は新しい挑戦で置き換えますが、星・最高点・図鑑・きらめきは残ります。
- 選択中のマス列・指やマウスのドラッグ・音源の再生位置は一時的な入力で、復元しません。漫画のページ位置、図鑑や説明のモーダルは保存しません。保存された終了結果だけは起動時に再表示します。
- blur・非表示・pagehideでは選択とドラッグを消し、音を止め、進行中のパズルは明示的な「パズルを再開」を待ちます。モーダルとpointercancelも選択を取り消します。盤面外へのpointerleaveとlostpointercaptureはドラッグ中だけ選択を取り消し、タップを離した後に決定ボタンへ移動するときの選択は保持します。**元版のマウスpointerleave時の自動決定は、安全のため取り消しに変更**しました。盤面から指やマウスを離れた後の遅いpointerupは決定しません。
- Enter／Spaceで選択、矢印でフォーカス移動、「つないだ仲間を決定」で実行。長押しの繰り返しキーは無視します。タップとドラッグも保持。ドラッグでも1個前への後戻りを最初のマスまで行えます（元版の始点を除外する処理を修正）。音は元の短い合成音だけで、WebAudioの生成・resume・suspendの例外やPromise拒否でゲームを止めません。
- 結果の再表示、再読込、同じボタンの遅れた入力で二重報酬を出しません。各モーダルのボタンは表示世代と現在のDOMノードを確認し、古い画面の遅れた開始・読書移動・結果・退避操作を無視します。ネイティブdialogの遅延closeイベントで、新しく開いた説明や復元を取り消さないようにしています。

## 保存・完全バックアップ

- 全フィールド、整数の範囲、重複・未知ID、星の連続解放、最高点、盤面、手数と得点・種類別個数の整合、終了条件と記録済み結果を検査。部分的な黙示修復はしません。未知の版、余分なフィールド、壊れたJSON、HTML文字列を進行データとして受け付けません。
- 書込みはWeb Locksの排他区間で元の保存バイト列を比較してから実行。別タブが更新したらそのタブの上書きを停止します。競合時は現在のメモリ内の記録をJSONに書き出し、再読込して状態を確認してください。
- Web Locks非対応時は危険な疑似ロックを使わず、**永続データには一切書かないメモリ内モード**です。保存拒否でもプレイとJSON書出しは続けられます。容量不足・競合・破損・非対応・拒否を上部に表示します。容量不足後は「保存を再試行」を使えます。破損した原データは通常プレイや再試行では上書きしません。
- 「記録・バックアップ」から全記録を書出し・復元。復元とリセットは確認後にだけ変更し、専用backupキーへ直前のメモリ状態と元の保存バイト列を退避します。退避または本保存に失敗した場合は、現在の状態と元の本保存を変更しません。「直前の記録を復元用JSONに書き出す」で、途中の盤面を含む直前の全状態を小さな通常形式のJSONとして出力し、そのファイルから復元できます。
- 壊れた原データもrawとして削らず内部に退避し、「退避した元データを保管用に書き出す」で別のテキストとして取り出せます。現在の保存元は「元の保存データを書き出す」で保管できます。復元用JSONにはこの巨大なrawを埋め込みません。これにより原データが大きい場合やJSONエスケープで膨らむ場合でも、自分で出力した復元用JSONがインポートの上限に拒まれません。保管用の壊れた原データはそのままゲームへインポートできる形式ではありません。退避は1世代分なので、大切な記録や壊れた原データはファイルでも保管してください。
- 保存非対応・拒否時の復元／リセット／途中の挑戦の置換は、確認にメモリ内だけであることを表示し、退避もメモリ内に残します。画面を閉じる前に必要なJSONを書き出してください。
- ファイル選択取消、同じファイルの再選択、新しいファイル読込、画面移動、閉じる、blur・非表示・pagehideの後に完了した古いファイル読込を無視。確認後にWeb Lock待ちとなった処理も、途中で取り消した場合は退避も本保存も行いません。
- ZatuPlayへの戻りは、現在の状態が未保存なら確認。ブラウザを閉じる際も未保存なら標準の離脱警告を要求しますが、ブラウザ・端末によって警告は表示されない場合があります。

保存は同じ端末・ブラウザ・サイト内だけで、クラウド同期しません。強制終了・電源断では最後の非同期保存が間に合わない場合があります。プライベートモード、保存容量、サイトデータ削除にも注意してください。専用service workerはなく、オフライン再起動は保証しません。初回のファイル読込後のパズルに外部APIや録音音源は使いません。ブラウザの画像キャッシュやサイト全体のPWAの状態によって、未読の漫画の読込には通信が必要です。

## 出典・ファイル整合性

`provenance.json` に原本APKのファイル名・サイズ・SHA-256、抽出118ファイルのサイズ・SHA-256、保持した115画像とCSS、および全章テキスト部分のハッシュを記録しています。署名、DEX、APKラッパー、秘密鍵、非公開の保存場所や共有IDは配布しません。

## 公開Chromeでの初回確認と修正状況

2026-11-12、先行テスト配置の **0.3.0-web.1** を実Chromeで確認しました。タイトルと原画、第1話の導入・盤面表示、Enter／Spaceによる斜めの3個選択と始点までの1段階ずつの後戻りは確認できました。

その際、タップで選んだ3個から盤面外の「決定」ボタンへマウスを移すと、pointerleaveが選択を消し、「同じ仲間を３個以上つなごう。」と表示する不具合を確認しました。手数と得点は変化しませんでした。**0.3.0-web.2では、pointerleaveとlostpointercaptureによる取消をドラッグ中だけに限定**しています。タップ終了後の選択は決定まで保持し、ドラッグ中の盤面離脱は従来どおり安全に取り消します。pointercancelによる取消は保持。

修正後の22自動スイートと独立した入力・保存の確認は合格しました。画像は全115点を変更せず、保存形式と専用キーも変更していません。0.3.0-web.2の実Chrome再確認では、残っていた第1話の途中盤面を復元し、斜めのタップ3個→盤面外の決定で30点・残り17手、Enter／Spaceで3個選択→始点まで1段階ずつ戻る→選び直して決定で60点・残り16手となり、保存済み表示を確認しました。

続く通常のドラッグでは、マス間の隙間を通ると選択が消え、得点と手数が変化しない別の不具合を確認しました。pointermoveでマスが見つからない場合を一律に盤面外として扱っていたためです。**0.3.0-web.3の修正は**、盤面内の隙間・余白・マスではない子要素では経路を維持し、本当の盤面外・nullのヒット・pointerleave・pointercancel等では取り消します。修正前に失敗する回帰テストを追加し、修正後の23スイートと独立した10項目の確認が合格しました。**0.3.0-web.3の実Chrome再確認はまだ行っていません。** 実際のクリア・次話解放・ファイル選択・復元・2タブ・30手エンドレスは未確認です。途中の60点・残り16手の記録を保持したまま、再配置後の確認を待っています。

最初のブラウザではChromiumの「エラーコード: 9」が表示され、画面の再読込後にChromium自体が終了しました。新しいタブを作成して回復した後は盤面操作まで確認できましたが、このブラウザ終了の原因は特定していません。ゲームの不具合と断定せず、上の再現した入力不具合とは区別しています。

## 公開Chromeでの通常UI手順

1. ZatuPlayから起動し、0.3.0-web.3・保存状態・戻りリンクを確認。第1話の「このお話で遊ぶ」→「パズルをはじめる」。ヒント→決定を15回行うと450点・残り3手・星1・きらめき20でクリアできます。途中で自動並べ直しが起きてもヒントは3個を示します。第2話が解放され、再読込で結果と記録が復元されることを確認。
2. 第2話は650点／18手なので、3個ずつだけでは足りません。4個80点・5個150点・6個240点を利用。クリア後、第3話では丸い「チーボウくん」を合計12個つなぐ目標を確認。他の種類では対象個数が増えないこと、達成時にコロンボくんが図鑑へ加わることを確認。対象が少ないときは他の種類を消して落下させるか、3回のおたすけを使います。
3. 第8話まで進んだら「5個以上を3回」を確認。ヒントは5個の経路を優先し、なければ3個。短い連鎖では回数が増えず、5個以上で1回増えることを確認。第13話は同条件で4回。普通のプレイを省略して検証用JSONから途中の記録を復元した場合は、その前提と、完走していない範囲を検証報告に明記してください。
4. 盤面で上下左右とななめのタップ→決定、ドラッグして離す、1個前に戻る、混色・短い選択・選択取消を確認。Tabと矢印でマスへ移り、Enter／Spaceで同じ種類を選択して決定。モーダル、別タブ、盤面外へ移動、pointercancel後の古い入力が決定されないことを確認。blur後は「パズルを再開」を押します。
5. 小道へ戻ると途中の盤面は保持。再読込→「途中からつづける」で盤面・残り手数・得点・おたすけ・音を確認。別の挑戦を始める確認を取り消しても保持されること。結果の「もう一度」「次のお話」「小道」、終了済み盤面の「結果を見る」を繰り返してもボーナスを二重に受け取らないこと。
6. 小道の「とことんサクサク」でヒント→決定を30回。30手使い切って900点の結果・最高点を確認（3個のヒントだけの場合）。再読込、再挑戦、結果再表示で最高点と記録が保たれること。
7. 進行前でも第15話の「原作を読む」が開くこと。1/7では前が無効、7/7では次が無効。全15表紙、代表の第1・3・8・15話ページを開き、長いページをスクロール。第15話最終ページの記念写真を確認。図鑑の7人とゲスト3人は該当の解放条件で確認。
8. 記録JSONを実際にダウンロードし、数手進めてから同じファイルを選択。取消なら進行を保持、確認なら完全復元。再び同じファイルを選べること、直前の退避JSONと元データを書き出せること、リセット取消と確認、退避からの復元を確認。
9. 同じURLを2タブで開き、片方だけを保存してからもう片方で操作。後続の競合警告と先行記録の保護を確認。保存拒否・容量不足・Web Locks非対応が実機で再現できなければ、その部分をモデル確認と区別して報告。
10. 幅360px程度でヘッダー・盤面・漫画・結果・バックアップ画面、フォーカス表示、音ON/OFFと復帰、コンソールエラー、ZatuPlayとの往復を確認。画像115点と大きな漫画の表示は実ブラウザでも別途確認します。
