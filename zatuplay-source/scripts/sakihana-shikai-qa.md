# 咲華詩界 0.4.0-web.1 公開Chrome確認手順

本書は確認レシピであり、実施済み報告ではない。ゲーム `/games/sakihana-shikai/` の公開後、普通のUIのみで実行する。テスト用状態注入はしない。

## 座標

キャンバスの実表示範囲を左L・上T・幅W・高さHとする。全画面座標は次の式でクリックする。原ゲームの座標は1000×500。画面サイズが変わってもこの比率は一定。

| 対象 | キャンバス内位置 | 画面で確認する結果 |
|---|---|---|
| 左の光 | L + 0.240W, T + 0.640H | 「1 / 3 の言葉を見つけました。」 |
| 右の光 | L + 0.740W, T + 0.580H | 「2 / 3 の言葉を見つけました。」 |
| 上の光 | L + 0.490W, T + 0.280H | 「３つの言葉が揃いました。中央の詩碑へ。」 |
| 詩碑の足元 | L + 0.500W, T + 0.490H | 旅人が詩碑に到着し、Eまたは調べるで全文が開く |
| 案内役の足元 | L + 0.365W, T + 0.760H | 旅人が近づき「E：話す」が現れる |

上の光は浮遊して数ピクセル上下するが、判定距離30なので固定座標でよい。固定時間の待機ではなく、毎回の新しい画面観察で移動・収集を確認する。進行表示は `#message`、断片は `#fragment`。詩碑操作ボタン `#interact` は常に有効で、遠ければ「中央の詩碑まで歩いてみよう。」と表示され、歩行は続く。近づいてから再操作すると `#reader` が開き、`#count` が増える。例: W=1000,H=500,L=T=0なら (240,320)→(740,290)→(490,140)→(500,245)。

## 通常操作で第2章まで

1. ブラウザカタログから起動し、版0.4.0-web.1、3つの光、主人公と案内役、保存状態を確認。別の同ゲームタブは閉じておく。
2. 3つの光→詩碑の順で上記座標をクリック。中央でEを1回、または「詩碑を調べる」。原詩の全文と番号0001、1/2,183を確認。Escapeまたは閉じる。
3. お気に入り登録。案内役の足元まで歩いてE、導入→助言→現在の光の数に応じた言葉→旅に戻るを確認。「登場人物を見る」の会話人数1/49も確認。
4. 「次の詩」で次へ。同じ3つの光と詩碑を歩き、詩を開いて閉じる。合計10篇まで繰り返す。途中、光1つ/2つでも再読み込みし収集状態が残ることを確認できる。
5. 「不思議な詩の物語」で第2章「届かない手紙」の本文、第3章「50篇との出会いで解放」を確認。再読み込み後も10/2,183と2/10章が残ることを確認。
6. 図鑑で第1篇の題名または0001を検索し、お気に入りのみをオン。該当詩へ戻れることと3つの光の収集済み状態を確認。絞り込みをオフに戻す。
7. 図鑑で2183を検索して最後の詩へ。既読数が増えないこと、「次の詩」で1に戻り「前の詩」で2183へ戻ることを確認。図鑑からもともと自由に移動できる原仕様。
8. 登場人物に全50種類と画像があること、検索と初登場の詩への移動、複数の案内役の顔と台詞を確認。特に第2篇の案内役「しずく」のゲーム内画像と図鑑画像の色を確認する。試験用のネイティブCanvasでは一部が黒く、Inkscapeでは淡い青になるレンダラー差が見られた。原SVGは変更していないため、Chromeの実際の見え方を原SVGと比較し、結果を報告する。

## 保存・中断・戻る

- 音オン、少し移動して約1秒以上待ち、再読み込みで位置・音設定を確認。操作後に短い合成音を確認。ミュートで止まること、音なしでも遊べることを確認。
- 「旅の記録を保存」で実ファイルがダウンロード一覧に出ることを確認。「記録を読み込む」→そのファイル→キャンセル。次に同じファイル→確認→再開。復元前バックアップを別ファイルで保存し、実ファイルを確認。破損JSONの拒否も確認。
- 画面内タップで歩き始めた直後に他タブへ移る。戻っても停止し、「再開」後に古い目的地へ勝手に歩かないことを確認。矢印を押しながら図鑑を開き、閉じても歩き続けないことを確認。検索欄のWASDは文字入力になることを確認。
- 別タブで同ゲームを開くと「別のタブが保存中」でメモリ内のみとなることを確認。別タブで進めても元タブの記録が上書きされないことを確認。2つ目を閉じて元タブの保存を確認。
- ZatuPlayへ戻るリンク→ブラウザカタログへ→ゲーム再起動。履歴復帰時に自動保存再開のための再読み込み案内が出る場合は案内に従う。
- 1,000×500のCanvas実描画はモデルで確認済みだが、公開Chromeのレイアウト・実ダウンロード・実音・スマートフォンはここで別に確認する。全2,183篇の手動読了やオフライン起動を確認済みとしない。
