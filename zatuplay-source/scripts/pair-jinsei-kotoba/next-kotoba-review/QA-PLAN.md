# 全国ことばRPG 実UI QA計画
2026-11-12 / 実施者：公開担当。これは計画であり実ブラウザ合格記録ではない。
対象：next-kotoba-port/game の現候補。ゲーム・保存データをコンソールで改変せず、通常UIだけで実施する。

## 事前と記録
- 公開予定URL・配信版/コミット・ブラウザ/OS・幅を記録。既存利用者の進行は壊さず、専用テストプロファイルが望ましい。
- 保存状態「このブラウザに保存済み」を確認。未保存/メモリ内のみであればその理由を記録し、永続化合格としない。
- 初回タイトルで当日ログイン1オーブ。既存記録なら開始値を記録し、絶対値より差分で判定。
- スクリーンショット：タイトル、問題、unit完了、JSON復元結果、地図、別タブ保存状態。

## A. 第1unitの最短自然完了（2問）
1. 「ステージセレクトへ」→「北海道」（STAGE 01）→「未クリアから挑戦」。初期状態なら先頭unit「札幌市」になる。直接一覧先頭の「札幌市」でも同じ。
2. 問題1「次の地名のうち、北海道・札幌市に含まれるのは？」→ **中央区**。
3. 正解表示・選択肢無効化を確認。「つづける →」。
4. 問題2「北海道・札幌市にある行政区はどれ？」→ **北区**。
5. 「この町・駅の収録問題を解き終えました。」を確認。ここでunit報酬1オーブが付く。「つづける →」で北海道一覧へ。
6. 札幌市が「2/2問 正解 · 復習できる」、全国正解数が開始時から+2、オーブが+1を確認。初期記録ならオーブ合計2、XP16・金16（UIに無ければJSON保存を読んで検査してよい）。県クリアは0/47のまま。unit完了と北海道全問クリアは別。
- 選択肢はシャッフルされる。位置/番号ではなく上記の文字を選ぶ。
- unit ID p1-札幌市。問題ID n2-p1-札幌市-0 / n2-p1-札幌市-1。
- 既存完了記録では未クリアボタンが別unitへ進むため、必ず札幌市を直接選ぶ。初回報酬テストは新規プロファイルで行う。

## B. 二重操作・復習・中断
- 正解後、同じ答えを再度押して追加報酬がないこと。
- 札幌市を復習し、同じ2問を解く。正解総数2・unit報酬オーブは増えない。復習XPは1問につき1増える仕様であり、XP無増加を期待しない。
- 復習の途中で「ステージへ戻る」または別タブ/バックグラウンドへ移動。復帰後は一覧から再開し、中断戦闘やコンボは復活しない。既に確定した正解記録は残る。
- 通常再読込で正解数・unit表示・オーブ保持。音設定も保持。

## C. JSON保存・復元・1世代退避
既存利用者データでは実施しない。まずUI「JSON保存」でテスト進行を手元へ保管する。
1. 2問完了の状態Aで「JSON保存」→ kotoba-browser.json が取得でき、開くと format=kotoba-browser/version=1/data.answered 2件/unitRewards 1件。ダウンロード表示だけでなくファイル取得を確認。
2. 「初期化」の確認を一度キャンセル：進行不変。その後実行し状態Bへ。正解0になるが同日のログイン報酬は再配布されない。
3. 「置換前へ戻す」→確認→状態Aの2問完了へ復帰。
4. 再び初期化してから「JSON復元」で保存したAを選び、置換確認→2問完了へ戻る。日次受取日を巻き戻さない仕様。
5. 同じJSONファイルを続けてもう一度選ぶ：選択イベントが再度発生し置換確認まで到達。キャンセル時は現進行維持。
6. ファイル選択自体のキャンセルでも進行不変。壊れたJSON/無関係JSON/1MiB超過を別テストファイルで試す場合、復元できませんと表示し進行を維持する。
7. 復元後に再読込して保持されること。
「元保存データ出力」は最後に永続化された原データ用で、現在メモリ進行のJSON保存とは別。取り違えない。

## D. 設定・基本UI・出典
- 「メニュー」→「効果音 ON / OFF」。ON操作/正解で短い合成音、OFFで無音を実聴取。ミュート端末なら聴取未確認と記録。
- ステージ検索「札幌市」/空検索、ページ送り、知識図鑑、遊び方を確認。北海道以外のクイズはロック状態のまま。
- 原素材の人物画像が表示されること。狭幅(390px程度)で答えとJSON操作が切れずタッチ可能なこと。
- 出典/利用条件ページと地理院リンクが実際に開くこと。ゲームが公式地理データ機関の認定作品と誤認される表示がないこと。

## E. 地図
1. 北海道画面「市区町村マップを開く」。読み込み完了、境界表示、一覧を確認。初回は詳細背景OFF（記憶済設定があると別）。
2. ドラッグ/＋/−/全域/中心部、検索「札幌市」、一覧選択→詳細2/2→「クイズを復習する」の遷移確認。
3. 「駅の表示」「広く表示」を切替、戻る操作でステージへ戻る。
4. 全国マップ「実際の地図で全国を見る」。別県の地図は閲覧できるがクイズ開始はロックされる。
5. 「詳細地図」をONにして地理院タイルが実際に現れること、OFFで消えること、保存した設定が再読込で反映されることを確認。通信未成功なら「タイル表示未確認」と明記。
6. 地図を開いて直ちに戻り、別県地図を開く。古い読み込み完了で現在画面が入れ替わらないこと。
7. オフライン試験では、事前に読み込んだ資源と未取得資源を分ける。ローカル配布境界であっても未キャッシュURLのネットワーク断からの初回取得は保証しない。通信失敗で固まらず戻れるか確認。背景タイル一括キャッシュ等は追加しない。

## F. 別タブ
- 同一オリジンのタブAで保存済状態を確保したまま、通常の新規タブBへ同URLを開く。Bは「メモリ内のみ…」となる（Web Locks対応時）。Bが保存済と偽表示しないこと。
- A/Bで異なる設定にしてもBがAの永続記録を上書きしないこと。タブ切替では中断がかかる仕様。
- Aを閉じた後、Bは自動所有権取得を期待せず再読込。Aの最後の保存内容から開き、保存済になること。Bのメモリ内操作を残したいなら再読込前JSON保存が必要。
- BFCacheの戻る復帰では保存再開のため再読込が必要という案内を確認できれば記録。
